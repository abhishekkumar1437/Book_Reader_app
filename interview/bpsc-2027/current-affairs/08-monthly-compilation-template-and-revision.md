Reading the news is only half the work. The other half is turning it into notes you can revise in minutes, again and again, until Prelims and then Mains. This chapter gives you ready-to-copy templates for every level — daily, weekly, monthly, by topic — and a revision plan tied to the 300 + 90 day roadmap. Copy them into your notebook or a document file once, and fill them in all year.

> **In simple words:** Your current-affairs notes should **shrink** as they move up: many daily lines → a short weekly list → one page per month → one sheet per theme. Each step is a revision. On exam day you revise a small set of pages that you have already read many times.

Keep **four** things:

| Notebook / file | What goes in | Template |
|---|---|---|
| **1. Daily register** | Dated daily notes from the newspaper | Template A |
| **2. Monthly file** | One-page monthly summary + Bihar page + recall questions | Templates C, E, H |
| **3. Static topic files** (six) | Background facts that you add to the chapters of this book: organisations, indices, defence/space, environment, awards/sports, schemes | Use the tables in chapters 02–07 |
| **4. Quick sheets** | Appointments, days and themes, places in news, "firsts" | Templates F, G |

> **Remember:** Paper or digital — both work. Choose one and do not switch. If digital, keep one document per month and one per static topic; search makes revision faster. If paper, use a loose-leaf file so you can add pages to topic sections.

## Template A — Daily note

Write 5–10 lines a day. Use the W-S-B-F-M questions from Chapter 01.

| Date | Topic (syllabus tag) | What happened (1 line) | Background (1–2 lines) | Exam fact | Mains? | Bihar? |
|---|---|---|---|---|---|---|
| __ /__ /____ | IR / Polity / Eco / Env / S&T / Bihar / Misc | | | | Y / N | Y / N |
| | | | | | | |
| | | | | | | |

**Syllabus tags:** IR = international relations and organisations; Polity = constitution, laws, courts, elections; Eco = economy, budget, banking, schemes; Env = environment, wildlife, climate; S&T = science, defence, space, technology; Bihar = anything about Bihar; Misc = awards, sports, books, days, appointments.

> **Common mistake:** Writing paragraphs. A daily note is a memory hook, not an essay. If you need more, the item probably deserves a Mains issue brief (Template D).

## Template B — Weekly review (every 7th day)

- [ ] Read all seven days of daily notes once.
- [ ] Check PIB for the week's releases on the topics you tagged.
- [ ] Move background facts into the six static topic files.
- [ ] Write 10 recall questions from the week (Template H) and answer them without looking.
- [ ] Mark items that need a Mains brief (Template D).
- [ ] Update trackers: schemes (Chapter 07), indices (Chapter 03), awards/sports (Chapter 06).

## Template D — Mains issue brief (one per big issue)

Use this for issues that can come as a 38-mark question in GS Paper I (current events) or GS Paper II. One page per issue. The method of writing full answers is in [Current Events Model Answers](/interview/bpsc-2027/mains-answer-writing/current-events-model-answers).

| Part | Notes |
|---|---|
| **Issue** | (name, in a question form: "Should India join RCEP?") |
| **Background** | 3–4 lines: history, law, organisation |
| **What happened recently** | Dates, decisions, numbers (with source and date) |
| **Why it matters for India** | 3–4 points: economy, security, society, environment |
| **Bihar angle** | 2–3 points: impact on Bihar, Bihar's own example or data |
| **Different views** | Government's view / critics' view / experts' view |
| **Data to quote** | 2–3 numbers with source and year |
| **Way forward** | 3–4 practical points |
| **One-line conclusion** | Balanced, forward-looking |

**Suggested issues to keep briefs on (stable themes; update facts):**

- [ ] India's neighbourhood: Nepal, Bangladesh, Sri Lanka, Myanmar — and Bihar's border
- [ ] India in BRICS, SCO, Quad and G20 (multi-alignment)
- [ ] Climate change, COP outcomes and India's NDC
- [ ] Floods in North Bihar and India–Nepal water cooperation
- [ ] New rural employment law (VB-G RAM G) and rural distress
- [ ] Census 2027, caste enumeration, delimitation and women's reservation
- [ ] Migration from Bihar and welfare portability (ONORC, e-Shram)
- [ ] Digital public infrastructure (UPI, Aadhaar, data protection)
- [ ] AI and jobs; IndiaAI Mission
- [ ] Space programme milestones and their development uses
- [ ] Nutrition and hunger (GHI, NFHS) — Bihar's stunting
- [ ] Bihar's position in NITI Aayog indices and the way forward
- [ ] Wetlands and biodiversity of Bihar (Ramsar sites, dolphin)
- [ ] Federal finance: CSS sharing, Finance Commission, special category demand

> **Memory trick:** Ask questions in the forms the exam uses: "**Who** publishes…", "**Where** is…", "**Which** country/district…", "**When** was… launched", "**What** is the first…". Five W-question types cover most current-affairs facts.

## Revision plan

### The 1-7-30 rule for current affairs

| When | What to revise | Time |
|---|---|---|
| **Next day** | Yesterday's daily notes (part of the 15-minute daily revision block) | 5 min |
| **Day 7** | The whole week (Template B) | 30–40 min |
| **Day 30** | The month (Template C + recall questions) | 1–2 h |
| **Every 3 months** | All monthly one-pagers so far + trackers | 3–4 h |

### By phase of the roadmap

| Phase | Days | Current-affairs revision task |
|---|---|---|
| 0–1 | 1–133 | Daily notes, weekly review, monthly one-pager. Back-fill one older month every two weeks |
| 2 | 134–196 | Same routine. Days 183–196: read this book; fill all static topic files; finish back-filling to March 2026 |
| 3 | 197–245 | Same routine + **one Mains issue brief a week** (Template D) and one current-events answer a week |
| 4 | 246–300 | See the Prelims plan below |
| 5 | 301–390 | See the Mains plan below |

### Prelims mode (Days 246–300)

| Days | Task |
|---|---|
| 246–260 | Revise all monthly one-pagers from March 2026 (first full round). Update all trackers (schemes, indices) from PIB and official sites |
| 261–275 | Fill **Template F (appointments)** and **Template G (days, themes, places)** fresh. Revise static topic files (chapters 02–07 tables) |
| 276–285 | Second round of monthly one-pagers; redo all recall questions marked wrong |
| 286–294 | Last 2–3 months in detail from your daily notes; one "last months" compilation |
| 295–300 | Only quick sheets: latest ranks sheet, appointments, Bihar page summaries, schemes quick revision box. No new sources |

> **Common mistake:** Buying a new "year-end current affairs" book in the last two weeks. You will find 500 new facts and lose confidence. Trust your own notes; use a new source only to check gaps in your one-pagers.

### Mains sprint (Days 301–390)

Re-arrange the year's notes **by theme**, not by month, because Mains questions are thematic.

| Theme sheet | Sources from your notes |
|---|---|
| India and the world (neighbours, groupings, summits) | IR tags + Chapter 02 file |
| Economy, budget and schemes | Eco tags + Chapter 07 tracker + Union and Bihar Budgets |
| Governance, laws and courts | Polity tags |
| Environment, climate and disasters | Env tags + Chapter 05 file |
| Science, technology, defence and space | S&T tags + Chapter 04 file |
| Society (health, education, women, migration) | Mixed tags + indices |
| **Bihar development** | All Bihar pages + Bihar Economic Survey |

For each theme sheet, write: 5 key events with dates, 5 numbers with sources, 3 Bihar examples, and 2 debates (for and against). Practise one GS I current-events answer every two days using these sheets.

## Key terms

| Term | Simple meaning |
|---|---|
| One-pager | A single page that summarises a month or a topic |
| Issue brief | A one-page note on one big issue, prepared for descriptive answers |
| Back-filling | Covering months that passed before you started, using compilations |
| Quick sheet | A short list of fast-changing facts (appointments, themes) made close to the exam |
| Theme sheet | Notes re-arranged by subject instead of by month, for Mains |
| Recall test | Answering questions from memory without looking at notes |

### Answers

1. Daily register, monthly file, six static topic files, quick sheets.
2. 5–10 lines.
3. IR, Polity, Eco, Env, S&T, Bihar, Misc.
4. Issue, background, recent events, why it matters for India, Bihar angle, different views, data, way forward, one-line conclusion.
5. Office holders change often; late notes are correct and fresh at exam time.
6. February (Bihar Budget in February–March).
7. The Global Hunger Index (and the IMF World Economic Outlook); the Nobel Prizes are also announced in October.
8. Revise the next day, on Day 7, and on Day 30 (then every three months).
9. Revise only quick sheets — latest ranks, appointments, Bihar summaries, schemes box — with no new sources.
10. Mains questions are asked by theme (economy, environment, IR, Bihar), not by month.

### Mains question

**Prepare a Mains issue brief (Template D) on "Floods in North Bihar and India–Nepal cooperation" and then write a 300-word answer from it.** (38 marks)

Model answer outline:
- **Intro:** About three-quarters of Bihar's area is flood-prone (commonly cited figure — check the latest Bihar Economic Survey); Kosi, Gandak, Bagmati, Kamla rise in Nepal.
- Body:
  - Background: Kosi Agreement 1954, Gandak Agreement 1959; Kosi barrage at Bhimnagar (Nepal); 2008 Kusaha breach.
  - Recent: the year's flood events, embankment breaches, central and state relief (fill from your notes).
  - Why it matters: lives, crops, migration, silt-laden rivers changing course.
  - Bihar angle: flood management plans, embankments, early warning with satellite data, Jal-Jeevan-Hariyali.
  - India–Nepal: proposed high dam on the Kosi (Sapta Kosi project), data sharing, joint commissions.
  - Way forward: basin-level planning, room for rivers, flood-plain zoning, better forecasting, community preparedness.
- **Conclusion:** Bihar's flood problem is an international river-basin problem; cooperation with Nepal and local resilience must go together.
