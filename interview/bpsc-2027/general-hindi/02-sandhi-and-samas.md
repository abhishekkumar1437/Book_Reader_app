संधि और समास व्याकरण के ऐसे दो विषय हैं, जो सामान्य हिंदी के प्रश्नपत्र में लगभग हर वर्ष आते हैं। आपसे किसी शब्द का संधि-विच्छेद करके संधि का नाम पूछा जाता है, या किसी समस्त पद का समास-विग्रह करके समास का भेद पूछा जाता है। दोनों नियमों पर आधारित हैं, इसलिए यदि आप एक बार नियम सीख लें, तो ये प्रश्नपत्र के सबसे भरोसेमंद अंक बन जाते हैं।

> **सरल शब्दों में:** **संधि** दो शब्दों के मिलने के स्थान पर दो **ध्वनियों (वर्णों)** को जोड़ती है: विद्या + आलय = विद्यालय (आ + आ मिलकर एक आ बन गया)। **समास** बीच के जोड़ने वाले शब्दों को हटाकर दो **शब्दों** को जोड़ता है: राजा का पुत्र = राजपुत्र ("का" हट गया)। संधि ध्वनि से जुड़ी है; समास अर्थ से।

## संधि और समास — मूल अंतर

| आधार | संधि | समास |
|---|---|---|
| क्या जुड़ता है | दो **वर्ण** (अक्षर/ध्वनियाँ) | दो या अधिक **पद** (शब्द) |
| क्या बदलता है | मिलने के स्थान पर ध्वनि बदल जाती है | जोड़ने वाले शब्द (विभक्ति, "और", "जो" आदि) हट जाते हैं |
| तोड़ने को क्या कहते हैं | **संधि-विच्छेद** | **समास-विग्रह** |
| उदाहरण | सूर्य + उदय = सूर्योदय | सूर्य का उदय = सूर्योदय |
| तोड़ते समय चिह्न | + (धन चिह्न) | शब्दों को पूरा खोलकर लिखा जाता है |

> **याद रखें:** एक ही शब्द में दोनों हो सकते हैं। **सूर्योदय** = सूर्य + उदय (गुण संधि) **और** सूर्य का उदय (तत्पुरुष समास)। प्रश्न ध्यान से पढ़ें: यदि "संधि-विच्छेद" पूछा है, तो + वाला रूप दें; यदि "समास-विग्रह" पूछा है, तो खुला हुआ वाक्यांश दें।

### 1. स्वर संधि (स्वर + स्वर)

**परिभाषा:** स्वर के साथ स्वर के मेल से होने वाले परिवर्तन को स्वर संधि कहते हैं।

#### (क) दीर्घ संधि

**नियम:** दो **सवर्ण (समान) स्वर** — ह्रस्व हों या दीर्घ — मिलकर उसी का **दीर्घ** स्वर बना देते हैं।

<div class="formula">

| नियम | परिणाम |
|---|---|
| अ/आ + अ/आ | **आ** |
| इ/ई + इ/ई | **ई** |
| उ/ऊ + उ/ऊ | **ऊ** |

</div>

| शब्द | संधि-विच्छेद | नियम |
|---|---|---|
| विद्यालय | विद्या + आलय | आ + आ = आ |
| हिमालय | हिम + आलय | अ + आ = आ |
| धर्मार्थ | धर्म + अर्थ | अ + अ = आ |
| परमार्थ | परम + अर्थ | अ + अ = आ |
| सत्यार्थी | सत्य + अर्थी | अ + अ = आ |
| देवालय | देव + आलय | अ + आ = आ |
| महात्मा | महा + आत्मा | आ + आ = आ |
| रत्नाकर | रत्न + आकर | अ + आ = आ |
| रवींद्र | रवि + इंद्र | इ + इ = ई |
| गिरीश | गिरि + ईश | इ + ई = ई |
| कवीश्वर | कवि + ईश्वर | इ + ई = ई |
| मुनींद्र | मुनि + इंद्र | इ + इ = ई |
| सतीश | सती + ईश | ई + ई = ई |
| महींद्र | मही + इंद्र | ई + इ = ई |
| भानूदय | भानु + उदय | उ + उ = ऊ |
| लघूर्मि | लघु + ऊर्मि | उ + ऊ = ऊ |
| वधूत्सव | वधू + उत्सव | ऊ + उ = ऊ |
| भूर्ध्व | भू + ऊर्ध्व | ऊ + ऊ = ऊ |

#### (ख) गुण संधि

**नियम:** **अ/आ** के बाद **इ/ई, उ/ऊ, ऋ** आएँ, तो क्रमशः **ए, ओ, अर्** हो जाते हैं।

<div class="formula">

| नियम | परिणाम |
|---|---|
| अ/आ + इ/ई | **ए** |
| अ/आ + उ/ऊ | **ओ** |
| अ/आ + ऋ | **अर्** |

</div>

| शब्द | संधि-विच्छेद | नियम |
|---|---|---|
| नरेंद्र | नर + इंद्र | अ + इ = ए |
| सुरेश | सुर + ईश | अ + ई = ए |
| गणेश | गण + ईश | अ + ई = ए |
| महेश | महा + ईश | आ + ई = ए |
| रमेश | रमा + ईश | आ + ई = ए |
| यथेष्ट | यथा + इष्ट | आ + इ = ए |
| सूर्योदय | सूर्य + उदय | अ + उ = ओ |
| परोपकार | पर + उपकार | अ + उ = ओ |
| महोत्सव | महा + उत्सव | आ + उ = ओ |
| जलोर्मि | जल + ऊर्मि | अ + ऊ = ओ |
| गंगोर्मि | गंगा + ऊर्मि | आ + ऊ = ओ |
| नवोढ़ा | नव + ऊढ़ा | अ + ऊ = ओ |
| देवर्षि | देव + ऋषि | अ + ऋ = अर् |
| महर्षि | महा + ऋषि | आ + ऋ = अर् |
| सप्तर्षि | सप्त + ऋषि | अ + ऋ = अर् |
| राजर्षि | राज + ऋषि | अ + ऋ = अर् |

#### (ग) वृद्धि संधि

**नियम:** **अ/आ** के बाद **ए/ऐ** आए, तो **ऐ** हो जाता है; **ओ/औ** आए, तो **औ** हो जाता है।

| शब्द | संधि-विच्छेद | नियम |
|---|---|---|
| एकैक | एक + एक | अ + ए = ऐ |
| सदैव | सदा + एव | आ + ए = ऐ |
| तथैव | तथा + एव | आ + ए = ऐ |
| मतैक्य | मत + ऐक्य | अ + ऐ = ऐ |
| महैश्वर्य | महा + ऐश्वर्य | आ + ऐ = ऐ |
| वनौषधि | वन + ओषधि | अ + ओ = औ |
| महौषधि | महा + ओषधि | आ + ओ = औ |
| जलौघ | जल + ओघ | अ + ओ = औ |
| महौज | महा + ओज | आ + ओ = औ |
| परमौदार्य | परम + औदार्य | अ + औ = औ |

> **स्मरण युक्ति:** **गुण** = "**ए-ओ-अर्**" (एक सीढ़ी ऊपर), **वृद्धि** = "**ऐ-औ**" (एक सीढ़ी और ऊपर)। अ + इ → ए (गुण); अ + ए → ऐ (वृद्धि)।

#### (घ) यण संधि

**नियम:** **इ/ई, उ/ऊ, ऋ** के बाद कोई **भिन्न (असवर्ण)** स्वर आए, तो ये क्रमशः **य्, व्, र्** बन जाते हैं।

<div class="formula">

| नियम | परिणाम |
|---|---|
| इ/ई + असमान स्वर | **य्** + वही स्वर |
| उ/ऊ + असमान स्वर | **व्** + वही स्वर |
| ऋ + असमान स्वर | **र्** + वही स्वर |

</div>

| शब्द | संधि-विच्छेद | नियम |
|---|---|---|
| इत्यादि | इति + आदि | इ + आ = या |
| यद्यपि | यदि + अपि | इ + अ = य |
| अत्यधिक | अति + अधिक | इ + अ = य |
| प्रत्येक | प्रति + एक | इ + ए = ये |
| अभ्यागत | अभि + आगत | इ + आ = या |
| न्यून | नि + ऊन | इ + ऊ = यू |
| उपर्युक्त | उपरि + उक्त | इ + उ = यु |
| देव्यागम | देवी + आगम | ई + आ = या |
| स्वागत | सु + आगत | उ + आ = वा |
| अन्वय | अनु + अय | उ + अ = व |
| अन्वेषण | अनु + एषण | उ + ए = वे |
| मन्वंतर | मनु + अंतर | उ + अ = व |
| वध्वागमन | वधू + आगमन | ऊ + आ = वा |
| पित्राज्ञा | पितृ + आज्ञा | ऋ + आ = रा |
| मात्रानंद | मातृ + आनंद | ऋ + आ = रा |

> **स्मरण युक्ति:** यण संधि में जोड़ पर **आधा अक्षर + य/व/र** दिखता है: इ**त्या**दि, स्**वा**गत, पि**त्रा**ज्ञा। शब्द के बीच में "्य", "्व" या "्र" दिखे, तो सबसे पहले यण के बारे में सोचें।

#### (ङ) अयादि संधि

**नियम:** **ए, ऐ, ओ, औ** के बाद कोई भी स्वर आए, तो ये क्रमशः **अय्, आय्, अव्, आव्** बन जाते हैं।

| शब्द | संधि-विच्छेद | नियम |
|---|---|---|
| नयन | ने + अन | ए + अ = अय |
| शयन | शे + अन | ए + अ = अय |
| चयन | चे + अन | ए + अ = अय |
| नायक | नै + अक | ऐ + अ = आय |
| गायक | गै + अक | ऐ + अ = आय |
| गायिका | गै + इका | ऐ + इ = आयि |
| पवन | पो + अन | ओ + अ = अव |
| भवन | भो + अन | ओ + अ = अव |
| श्रवण | श्रो + अन | ओ + अ = अव |
| पावक | पौ + अक | औ + अ = आव |
| पावन | पौ + अन | औ + अ = आव |
| भावुक | भौ + उक | औ + उ = आवु |
| नाविक | नौ + इक | औ + इ = आवि |

> **सामान्य भूल:** **पवन = पव + न** लिखना। यह संधि है ही नहीं। शुद्ध विच्छेद **पो + अन** (अयादि) है। नयन, पवन, नायक, पावक जैसे शब्द देखने में सरल लगते हैं, पर ये परीक्षा के प्रसिद्ध प्रश्न हैं।

### 2. व्यंजन संधि (व्यंजन + स्वर / व्यंजन)

**परिभाषा:** व्यंजन का स्वर या व्यंजन के साथ मेल होने पर जो परिवर्तन होता है, उसे व्यंजन संधि कहते हैं।

पहले व्यंजनों के **वर्ग** याद कर लें। हर वर्ग में पाँच वर्ण होते हैं: पहला, दूसरा (कठोर), तीसरा, चौथा (कोमल) और पाँचवाँ (नासिक्य)।

| वर्ग | 1 | 2 | 3 | 4 | 5 (नासिक्य) |
|---|---|---|---|---|---|
| क-वर्ग | क | ख | ग | घ | ङ |
| च-वर्ग | च | छ | ज | झ | ञ |
| ट-वर्ग | ट | ठ | ड | ढ | ण |
| त-वर्ग | त | थ | द | ध | न |
| प-वर्ग | प | फ | ब | भ | म |

#### नियम 1 — पहला वर्ण तीसरा बन जाता है

यदि किसी वर्ग के **पहले वर्ण** (क्, च्, ट्, त्, प्) के बाद कोई **स्वर**, या किसी वर्ग का **तीसरा/चौथा वर्ण**, या **य, र, ल, व** आए, तो वह अपने ही वर्ग का **तीसरा वर्ण** (ग्, ज्, ड्, द्, ब्) बन जाता है।

| शब्द | विच्छेद | परिवर्तन |
|---|---|---|
| दिगंबर | दिक् + अंबर | क् → ग् |
| वागीश | वाक् + ईश | क् → ग् |
| दिग्गज | दिक् + गज | क् → ग् |
| अजंत | अच् + अंत | च् → ज् |
| षडानन | षट् + आनन | ट् → ड् |
| सदाचार | सत् + आचार | त् → द् |
| जगदीश | जगत् + ईश | त् → द् |
| सद्गति | सत् + गति | त् → द् |
| भगवद्भक्ति | भगवत् + भक्ति | त् → द् |
| अब्ज | अप् + ज | प् → ब् |

#### नियम 2 — पहला वर्ण पाँचवाँ (नासिक्य) बन जाता है

यदि पहले वर्ण के बाद **न** या **म** आए, तो वह अपने वर्ग का **पाँचवाँ वर्ण** बन जाता है।

| शब्द | विच्छेद | परिवर्तन |
|---|---|---|
| वाङ्मय | वाक् + मय | क् → ङ् |
| षण्मास | षट् + मास | ट् → ण् |
| जगन्नाथ | जगत् + नाथ | त् → न् |
| उन्नति | उत् + नति | त् → न् |
| चिन्मय | चित् + मय | त् → न् |
| सन्मार्ग | सत् + मार्ग | त् → न् |

#### नियम 3 — त् के बाद अन्य वर्ण

| त् + | क्या बनता है | उदाहरण |
|---|---|---|
| च / छ | च्च / च्छ | उत् + चारण = **उच्चारण**; सत् + चरित्र = **सच्चरित्र** |
| ज / झ | ज्ज / ज्झ | सत् + जन = **सज्जन**; उत् + ज्वल = **उज्ज्वल** |
| ट / ड | ट्ट / ड्ड | तत् + टीका = **तट्टीका**; उत् + डयन = **उड्डयन** |
| ल | ल्ल | उत् + लास = **उल्लास**; तत् + लीन = **तल्लीन** |
| श | च्छ | उत् + श्वास = **उच्छ्वास**; सत् + शास्त्र = **सच्छास्त्र** |
| ह | द्ध | उत् + हार = **उद्धार**; तत् + हित = **तद्धित**; उत् + हरण = **उद्धरण** |

#### नियम 4 — स्वर के बाद छ आए तो च्छ

| शब्द | विच्छेद |
|---|---|
| विच्छेद | वि + छेद |
| अनुच्छेद | अनु + छेद |
| परिच्छेद | परि + छेद |
| आच्छादन | आ + छादन |
| स्वच्छंद | स्व + छंद |

#### नियम 5 — म् के नियम

| म् + | क्या बनता है | उदाहरण |
|---|---|---|
| क से म तक (कोई भी स्पर्श वर्ण) | अनुस्वार (ं) या उसी वर्ग का पाँचवाँ वर्ण | सम् + कल्प = **संकल्प**; सम् + गम = **संगम**; सम् + तोष = **संतोष**; किम् + चित् = **किंचित्** |
| म | म्म | सम् + मान = **सम्मान**; सम् + मति = **सम्मति** |
| य, र, ल, व, श, ष, स, ह | अनुस्वार (ं) | सम् + योग = **संयोग**; सम् + सार = **संसार**; सम् + वाद = **संवाद**; सम् + हार = **संहार**; सम् + रक्षण = **संरक्षण** |

> **सामान्य भूल:** **सम्राट** = सम् + राट। यहाँ म् ज्यों-का-त्यों म् ही रहता है (अपवाद) — यह "संराट" **नहीं** बनता।

#### नियम 6 — न का ण बनना

एक ही शब्द में **ऋ, र, ष** के बाद **न** आए, तो वह **ण** बन जाता है (यदि बीच में कोई बाधक वर्ण न हो)।

| शब्द | विच्छेद |
|---|---|
| परिणाम | परि + नाम |
| प्रणाम | प्र + नाम |
| रामायण | राम + अयन |
| भूषण | भूष + अन |

#### नियम 7 — स का ष बनना

यदि **स** से पहले अ/आ के अतिरिक्त कोई स्वर (जैसे इ, उ) हो, तो प्रायः **स** का **ष** हो जाता है।

| शब्द | विच्छेद |
|---|---|
| अभिषेक | अभि + सेक |
| विषम | वि + सम |
| निषिद्ध | नि + सिद्ध |
| सुषुप्ति | सु + सुप्ति |

अपवाद: **अनुसरण** (अनु + सरण), **विस्मरण** (वि + स्मरण) — इनमें स नहीं बदलता।

### 3. विसर्ग संधि (विसर्ग ः + स्वर / व्यंजन)

**परिभाषा:** विसर्ग (ः) के साथ स्वर या व्यंजन के मेल से जो परिवर्तन होता है, उसे विसर्ग संधि कहते हैं।

| नियम | उदाहरण |
|---|---|
| **1. अः + अ / वर्ग का तीसरा, चौथा, पाँचवाँ वर्ण / य र ल व ह → ओ** | मनः + अनुकूल = **मनोनुकूल (मनोऽनुकूल)**; मनः + योग = **मनोयोग**; यशः + दा = **यशोदा**; मनः + बल = **मनोबल**; तपः + भूमि = **तपोभूमि**; अधः + गति = **अधोगति**; मनः + रथ = **मनोरथ** |
| **2. इः / उः + स्वर / तीसरा, चौथा, पाँचवाँ वर्ण / य र ल व → र्** | निः + आशा = **निराशा**; निः + गुण = **निर्गुण**; निः + धन = **निर्धन**; निः + मल = **निर्मल**; दुः + उपयोग = **दुरुपयोग**; दुः + बल = **दुर्बल**; आशीः + वाद = **आशीर्वाद** |
| **3. ः + च/छ → श्; ट/ठ → ष्; त/थ → स्** | निः + चल = **निश्चल**; निः + छल = **निश्छल**; दुः + चरित्र = **दुश्चरित्र**; धनुः + टंकार = **धनुष्टंकार**; नमः + ते = **नमस्ते**; मनः + ताप = **मनस्ताप**; दुः + तर = **दुस्तर** |
| **4. इः / उः + क, ख, प, फ → ष्** | निः + कपट = **निष्कपट**; दुः + कर = **दुष्कर**; निः + पाप = **निष्पाप**; निः + फल = **निष्फल** |
| **5. अः + क/प, कुछ शब्दों में → स्** | नमः + कार = **नमस्कार**; पुरः + कार = **पुरस्कार**; भाः + कर = **भास्कर** |
| **6. कुछ शब्दों में विसर्ग बना रहता है** | प्रातः + काल = **प्रातःकाल**; अंतः + करण = **अंतःकरण** |
| **7. ः + र → विसर्ग लुप्त, पहला स्वर दीर्घ** | निः + रोग = **नीरोग**; निः + रस = **नीरस**; निः + रव = **नीरव** |
| **8. अः + अ के अतिरिक्त कोई स्वर → विसर्ग लुप्त** | अतः + एव = **अतएव** |
| **9. ः + श/स → वही वर्ण, या विसर्ग बना रहता है** | निः + संदेह = **निस्संदेह / निःसंदेह**; दुः + शासन = **दुश्शासन / दुःशासन** |

> **सामान्य भूल:** **नीरोग** को "निरोग" लिखना। नियम 7 के अनुसार विसर्ग लुप्त होता है और **इ का ई** हो जाता है, इसलिए **नीरोग, नीरस, नीरव** ही शुद्ध हैं।

> **स्मरण युक्ति:** विसर्ग के लिए: "**अः → ओ, इः/उः → र्**" — इतने से ही आधे से अधिक प्रश्न हल हो जाते हैं। फिर **च-श, ट-ष, त-स** याद रखें (विसर्ग अगले वर्ण के वर्ग का ऊष्म वर्ण ले लेता है)।

|---|---|---|

| सुरेंद्र | सुर + इंद्र | गुण |

| अध्यक्ष | अधि + अक्ष | यण |
| पावन | पौ + अन | अयादि |
| सज्जन | सत् + जन | व्यंजन |

> **परीक्षा की दृष्टि से:** हर उत्तर इस रूप में लिखें — **शब्द = खंड + खंड (संधि का नाम)**। उदाहरण: "**हिमालय = हिम + आलय (दीर्घ स्वर संधि)**"। पूरा भेद लिखना (दीर्घ **स्वर** संधि) सबसे सुरक्षित है।

## भाग ख — समास

**परिभाषा:** दो या दो से अधिक शब्दों के मेल से बने नए सार्थक शब्द को **समास** कहते हैं। समास से बने शब्द को **समस्त पद** (सामासिक पद) कहते हैं और उसे तोड़ने की प्रक्रिया को **समास-विग्रह** कहते हैं।

- पहला शब्द = **पूर्वपद**; दूसरा शब्द = **उत्तरपद**।
- समास का भेद इससे तय होता है कि **कौन-सा पद प्रधान** है।

<div class="formula">

| समास | कौन-सा पद प्रधान | त्वरित पहचान |
|---|---|---|
| अव्ययीभाव | **पूर्वपद** (पहला) — वह अव्यय होता है | पूरा शब्द अव्यय की तरह काम करता है (यथाशक्ति, प्रतिदिन) |
| तत्पुरुष | **उत्तरपद** (दूसरा) | कोई कारक-चिह्न (को, से, के लिए, का, में) लुप्त होता है |
| कर्मधारय | **उत्तरपद** | विशेषण–विशेष्य या उपमान–उपमेय ("है जो", "के समान") |
| द्विगु | **उत्तरपद** | पहला पद **संख्या** होता है; अर्थ समूह का होता है |
| द्वंद्व | **दोनों** पद | बीच में "और / या / अथवा" छिपा होता है |
| बहुव्रीहि | **कोई नहीं** — तीसरी वस्तु का बोध | "है जिसका / जिसके" → शब्दों से बाहर का कोई व्यक्ति/वस्तु |

</div>

> **याद रखें:** **कामताप्रसाद गुरु** सहित कई मानक वैयाकरण **कर्मधारय** और **द्विगु** को **तत्पुरुष** के ही विशेष रूप मानते हैं। स्कूली पुस्तकें (एनसीईआरटी) और परीक्षाएँ **छह भेद** गिनाती हैं। परीक्षा में केवल "तत्पुरुष" न लिखें, विशिष्ट भेद (कर्मधारय / द्विगु) का नाम लिखें।

### 1. अव्ययीभाव समास

**नियम:** **पहला पद अव्यय** होता है (जैसे यथा, प्रति, आ, भर, बे), और पूरा शब्द अव्यय की तरह काम करता है। दोहराए गए शब्द (रातोंरात, घर-घर) भी प्रायः अव्ययीभाव बनाते हैं।

| समस्त पद | विग्रह |
|---|---|
| यथाशक्ति | शक्ति के अनुसार |
| यथासंभव | जितना संभव हो |
| यथाविधि | विधि के अनुसार |
| प्रतिदिन | प्रत्येक दिन / दिन-दिन |
| प्रत्येक | एक-एक |
| आजन्म | जन्म से लेकर |
| आमरण | मरण तक |
| भरपेट | पेट भरकर |
| बेखटके | बिना खटके के |
| बेकाम | बिना काम के |
| रातोंरात | रात ही रात में |
| हाथोंहाथ | हाथ ही हाथ में |
| बीचोंबीच | ठीक बीच में |
| निस्संदेह | संदेह के बिना |

### 2. तत्पुरुष समास

**नियम:** **दूसरा पद प्रधान** होता है; दोनों शब्दों के बीच का **कारक-चिह्न** लुप्त हो जाता है। जो कारक-चिह्न लुप्त होता है, उसी के नाम पर भेद का नाम होता है।

| भेद | लुप्त चिह्न | समस्त पद → विग्रह |
|---|---|---|
| कर्म तत्पुरुष | को | स्वर्गप्राप्त → स्वर्ग को प्राप्त; गगनचुंबी → गगन को चूमने वाला; ग्रामगत → ग्राम को गया हुआ; यशप्राप्त → यश को प्राप्त |
| करण तत्पुरुष | से / के द्वारा | तुलसीकृत → तुलसी द्वारा कृत; रेखांकित → रेखा से अंकित; हस्तलिखित → हस्त (हाथ) से लिखित; मनचाहा → मन से चाहा; शोकाकुल → शोक से आकुल |
| संप्रदान तत्पुरुष | के लिए | रसोईघर → रसोई के लिए घर; देशभक्ति → देश के लिए भक्ति; विद्यालय → विद्या के लिए आलय; गुरुदक्षिणा → गुरु के लिए दक्षिणा; हथकड़ी → हाथ के लिए कड़ी |
| अपादान तत्पुरुष | से (अलग होना) | देशनिकाला → देश से निकाला; पथभ्रष्ट → पथ से भ्रष्ट; रोगमुक्त → रोग से मुक्त; ऋणमुक्त → ऋण से मुक्त; जन्मांध → जन्म से अंधा |
| संबंध तत्पुरुष | का / के / की | राजपुत्र → राजा का पुत्र; गंगाजल → गंगा का जल; सेनापति → सेना का पति; राजमहल → राजा का महल; घुड़दौड़ → घोड़ों की दौड़; देशवासी → देश का वासी |
| अधिकरण तत्पुरुष | में / पर | वनवास → वन में वास; आपबीती → आप पर बीती; घुड़सवार → घोड़े पर सवार; नरोत्तम → नरों में उत्तम; शरणागत → शरण में आगत; आत्मविश्वास → आत्मा पर विश्वास; सिरदर्द → सिर में दर्द |
| नञ् तत्पुरुष | "न" (निषेध) | असत्य → न सत्य; अधर्म → न धर्म; अनादि → न आदि; अज्ञान → न ज्ञान; अनपढ़ → न पढ़ा हुआ; नास्तिक → न आस्तिक |

> **स्मरण युक्ति:** छह कारक-चिह्नों को एक वाक्य की तरह पढ़ें: "**को, से, के लिए, से, का, में**" = कर्म, करण, संप्रदान, अपादान, संबंध, अधिकरण। **करण** का "से" = "साधन से / के द्वारा"; **अपादान** का "से" = "अलग होना"।

### 3. कर्मधारय समास

**नियम:** दोनों शब्दों में **विशेषण–विशेष्य** या **उपमान–उपमेय (तुलना)** का संबंध होता है। दूसरा पद प्रधान होता है।

| समस्त पद | विग्रह | संबंध |
|---|---|---|
| नीलकमल | नीला है जो कमल | विशेषण–विशेष्य |
| महात्मा | महान है जो आत्मा | विशेषण–विशेष्य |
| परमानंद | परम है जो आनंद | विशेषण–विशेष्य |
| सज्जन | सत् (अच्छा) है जो जन | विशेषण–विशेष्य |
| महापुरुष | महान है जो पुरुष | विशेषण–विशेष्य |
| कालीमिर्च | काली है जो मिर्च | विशेषण–विशेष्य |
| चंद्रमुख | चंद्र के समान मुख | उपमान–उपमेय |
| कमलनयन | कमल के समान नयन | उपमान–उपमेय |
| करकमल | कमल के समान कर | उपमान–उपमेय |
| घनश्याम | घन के समान श्याम | उपमान–उपमेय |
| विद्याधन | विद्या रूपी धन | रूपक |
| क्रोधाग्नि | क्रोध रूपी अग्नि | रूपक |

### 4. द्विगु समास

**नियम:** **पहला पद संख्यावाचक विशेषण** होता है, और पूरा शब्द किसी **समूह (समाहार)** का बोध कराता है।

| समस्त पद | विग्रह |

### 5. द्वंद्व समास

| सीता-राम | सीता और राम | इतरेतर |
| अन्न-जल | अन्न और जल | इतरेतर |

| लेन-देन | लेन और देन | इतरेतर |

### 6. बहुव्रीहि समास

**नियम:** **कोई भी पद प्रधान नहीं** होता; दोनों मिलकर किसी **तीसरे व्यक्ति या वस्तु** की ओर संकेत करते हैं। विग्रह में "**है जिसका / जिसकी / जिसके**" आता है और फिर बताया जाता है कि किसकी बात है।

| समस्त पद | विग्रह | किसका बोध |
|---|---|---|
| दशानन | दस हैं आनन (मुख) जिसके | रावण |
| लंबोदर | लंबा है उदर जिसका | गणेश |
| गजानन | गज के समान आनन है जिसका | गणेश |
| पीतांबर | पीत (पीला) है अंबर जिसका | कृष्ण |
| गिरिधर | गिरि को धारण करता है जो | कृष्ण |
| चक्रपाणि | चक्र है पाणि (हाथ) में जिसके | विष्णु |
| चतुर्भुज | चार हैं भुजाएँ जिसकी | विष्णु |
| नीलकंठ | नीला है कंठ जिसका | शिव |
| त्रिलोचन | तीन हैं लोचन जिसके | शिव |
| चंद्रशेखर | चंद्र है शेखर (सिर) पर जिसके | शिव |
| मृत्युंजय | मृत्यु को जीत लिया है जिसने | शिव |
| वीणापाणि | वीणा है पाणि में जिसके | सरस्वती |
| हंसवाहिनी | हंस है वाहन जिसका | सरस्वती |
| षडानन | छह हैं आनन जिसके | कार्तिकेय |
| पंकज | पंक (कीचड़) में जन्म लेता है जो | कमल |
| दिगंबर | दिशाएँ ही हैं अंबर (वस्त्र) जिसके | शिव / जैन मुनि |

### परीक्षा के प्रसिद्ध भ्रम

**एक ही शब्द** जो विग्रह दिया जाए, उसके अनुसार अलग-अलग समास हो सकता है। यदि प्रश्न में केवल शब्द दिया हो, तो सबसे प्रचलित उत्तर दें — या दोनों विग्रह सहित लिख दें, यह सुरक्षित है।

| शब्द | एक अर्थ | दूसरा अर्थ |
|---|---|---|
| नीलकंठ | नीला है जो कंठ — **कर्मधारय** | नीला है कंठ जिसका (शिव) — **बहुव्रीहि** |
| पीतांबर | पीला है जो अंबर — **कर्मधारय** | पीला है अंबर जिसका (कृष्ण) — **बहुव्रीहि** |
| चतुर्भुज | चार भुजाओं का समूह — **द्विगु** | चार हैं भुजाएँ जिसकी (विष्णु) — **बहुव्रीहि** |
| त्रिलोचन | तीन लोचनों का समूह — **द्विगु** | तीन हैं लोचन जिसके (शिव) — **बहुव्रीहि** |
| दशानन | दस आननों का समूह — **द्विगु** | दस हैं आनन जिसके (रावण) — **बहुव्रीहि** |

> **सामान्य भूल:** जब प्रश्न **गणेश** का बोध चाहता हो, तब "लंबोदर = लंबा उदर (कर्मधारय)" लिख देना। देवताओं और व्यक्तियों के नाम (दशानन, गजानन, चक्रपाणि, पीतांबर) **बहुव्रीहि** ही माने जाते हैं, जब तक प्रश्न में स्पष्ट रूप से दूसरा विग्रह न दिया हो।

> **स्मरण युक्ति:** **"जिसका" आया तो बहुव्रीहि; "संख्या + समूह" आया तो द्विगु; "है जो / के समान" आया तो कर्मधारय।**

### एक ही शब्द में संधि और समास

| शब्द | संधि-विच्छेद | समास-विग्रह |
|---|---|---|
| विद्यालय | विद्या + आलय (दीर्घ) | विद्या के लिए आलय (संप्रदान तत्पुरुष) |
| देवालय | देव + आलय (दीर्घ) | देव का आलय (संबंध तत्पुरुष) |
| सूर्योदय | सूर्य + उदय (गुण) | सूर्य का उदय (संबंध तत्पुरुष) |
| महात्मा | महा + आत्मा (दीर्घ) | महान है जो आत्मा (कर्मधारय) |
| हिमालय | हिम + आलय (दीर्घ) | हिम का आलय (संबंध तत्पुरुष) |
| नरेंद्र | नर + इंद्र (गुण) | नरों में इंद्र (अधिकरण तत्पुरुष) |

> **बिहार से जुड़ाव:** अपने उत्तरों में बिहार के परिचित शब्दों को उदाहरण बना सकते हैं: **राजगृह** (राजा का गृह — संबंध तत्पुरुष), **ग्रामसभा** (ग्राम की सभा — संबंध तत्पुरुष), **जन्मभूमि** (जन्म की भूमि — संबंध तत्पुरुष), **जल-जीवन-हरियाली** (जल, जीवन और हरियाली — द्वंद्व), **शराबबंदी** (शराब की बंदी — संबंध तत्पुरुष)। परीक्षक नए और शुद्ध उदाहरणों को पसंद करते हैं।

## अभ्यास

### अभ्यास क — संधि-विच्छेद कीजिए और संधि का नाम लिखिए

### अभ्यास घ — स्पष्ट कीजिए

1. **चतुर्भुज** कभी द्विगु और कभी बहुव्रीहि क्यों होता है?
2. करण तत्पुरुष और अपादान तत्पुरुष में क्या अंतर है (दोनों में "से" आता है)?

### उत्तर

**क.**
1. रमेश = रमा + ईश (गुण) 2. इत्यादि = इति + आदि (यण) 3. महोत्सव = महा + उत्सव (गुण) 4. नायक = नै + अक (अयादि) 5. उज्ज्वल = उत् + ज्वल (व्यंजन) 6. निर्मल = निः + मल (विसर्ग) 7. सदैव = सदा + एव (वृद्धि) 8. जगदीश = जगत् + ईश (व्यंजन) 9. मनोरथ = मनः + रथ (विसर्ग) 10. गिरीश = गिरि + ईश (दीर्घ) 11. स्वागत = सु + आगत (यण) 12. संतोष = सम् + तोष (व्यंजन) 13. निष्फल = निः + फल (विसर्ग) 14. भवन = भो + अन (अयादि) 15. महर्षि = महा + ऋषि (गुण)

**ख.**
1. देवेंद्र (गुण) 2. स्वच्छ (यण) 3. उल्लास (व्यंजन) 4. नीरस (विसर्ग) 5. वनौषधि (वृद्धि) 6. सम्मान (व्यंजन) 7. पावन (अयादि) 8. दुर्गम (विसर्ग)

**ग.**
1. शक्ति के अनुसार — अव्ययीभाव 2. राजा का महल — संबंध तत्पुरुष 3. चार राहों का समूह — द्विगु 4. नीला है जो कमल — कर्मधारय 5. माता और पिता — द्वंद्व 6. दस हैं आनन जिसके अर्थात् रावण — बहुव्रीहि 7. हस्त से लिखित — करण तत्पुरुष 8. पथ से भ्रष्ट — अपादान तत्पुरुष 9. वन में वास — अधिकरण तत्पुरुष 10. चंद्र के समान मुख — कर्मधारय 11. तीन फलों का समूह — द्विगु 12. गिरि को धारण करता है जो अर्थात् कृष्ण — बहुव्रीहि 13. रसोई के लिए घर — संप्रदान तत्पुरुष 14. न धर्म — नञ् तत्पुरुष 15. भला या बुरा — द्वंद्व (वैकल्पिक)

**घ.**
1. "चार भुजाओं का समूह" — पहला पद संख्या है और अर्थ समूह का है, इसलिए **द्विगु**। "चार हैं भुजाएँ जिसकी अर्थात् विष्णु" — शब्द किसी तीसरे व्यक्ति की ओर संकेत करता है, इसलिए **बहुव्रीहि**। समास का निर्णय विग्रह से होता है।
2. **करण** का "से" **साधन / के द्वारा** का अर्थ देता है (हस्तलिखित — हाथ से लिखा)। **अपादान** का "से" **अलग होने** का अर्थ देता है (देशनिकाला — देश से निकाला)।
