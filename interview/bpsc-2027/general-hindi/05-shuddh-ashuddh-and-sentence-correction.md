प्रायः बताया जाता है कि "वाक्य-विन्यास" खंड लगभग **25 अंकों** का होता है, और व्याकरण खंड में शब्द-स्तर की शुद्धि के प्रश्न भी आते हैं। प्रश्नों में लिखा होता है — "**शुद्ध कीजिए**" या "**निर्देशानुसार वाक्य बदलिए**"। अच्छी बात यह है कि अधिकतर अशुद्धियाँ कुछ ही नियमों से जुड़ी होती हैं — लिंग, वचन, 'ने' का नियम, पदक्रम और पुनरुक्ति। ये नियम समझ लें, तो आप लगभग हर वाक्य शुद्ध कर सकते हैं।

> **सरल शब्दों में:** किसी हिंदी वाक्य को शुद्ध करने के लिए क्रम से पाँच बातें जाँचें — (1) **वर्तनी** — शब्द की स्पेलिंग ठीक है या नहीं; (2) **लिंग** — संज्ञा पुल्लिंग है या स्त्रीलिंग, और क्या क्रिया/विशेषण उसके अनुसार है; (3) **वचन** — एकवचन है या बहुवचन; (4) **कारक और 'ने'** — सही परसर्ग (ने, को, से) लगा है या नहीं; (5) **पदक्रम और पुनरुक्ति** — कोई शब्द गलत स्थान पर तो नहीं, या एक ही अर्थ दो बार तो नहीं कहा गया।

## 1. वर्तनी — कारण सहित 45 शब्द

| अशुद्ध | शुद्ध | कारण |
|---|---|---|
| अत्याधिक | **अत्यधिक** | अति + अधिक (यण संधि) — बीच में 'आ' नहीं |
| अनाधिकार | **अनधिकार** | अन् + अधिकार |
| अध्यन | **अध्ययन** | अधि + अयन |
| अनुग्रहीत | **अनुगृहीत** | 'गृह्' धातु — 'ृ' लगेगा, '्र' नहीं |
| आर्शीवाद | **आशीर्वाद** | आशीः + वाद (विसर्ग → र्) — 'र्' 'व' के ऊपर आता है |
| इतिहासिक | **ऐतिहासिक** | '-इक' प्रत्यय लगने पर पहले स्वर की वृद्धि (इ → ऐ) |
| उज्वल | **उज्ज्वल** | उत् + ज्वल → 'ज्ज' |
| उपरोक्त | **उपर्युक्त** | उपरि + उक्त (यण संधि) |
| कवियत्री | **कवयित्री** | 'कवि' का मानक स्त्रीलिंग रूप |
| कृप्या | **कृपया** | कृपा + या (करण कारक का रूप) |
| ग्रहणी | **गृहिणी** | गृह (घर) + इणी |
| गुरू | **गुरु** | ह्रस्व 'उ' |
| शुरु | **शुरू** | दीर्घ 'ऊ' |
| साधू | **साधु** | ह्रस्व 'उ' |
| ज्योत्सना | **ज्योत्स्ना** | 'स्' + 'न' का संयुक्त रूप |
| दुरावस्था | **दुरवस्था** | दुः + अवस्था |
| द्रष्टि | **दृष्टि** | 'दृश्' धातु — 'ृ' लगेगा |
| निरपराधी | **निरपराध** | 'निर्' का अर्थ पहले से ही "रहित" है |
| निरोग | **नीरोग** | निः + रोग → 'नी' |
| परिक्षा | **परीक्षा** | परि + ईक्षा (दीर्घ संधि) |
| पश्चाताप | **पश्चात्ताप** | पश्चात् + ताप |
| प्रमाणिक | **प्रामाणिक** | '-इक' प्रत्यय से वृद्धि (प्र → प्रा) |
| प्रदर्शिनी | **प्रदर्शनी** | मानक रूप |
| पूज्यनीय | **पूजनीय / पूज्य** | दो प्रत्यय एक साथ |
| बुद्धिमानता | **बुद्धिमत्ता** | मानक भाववाचक संज्ञा |
| मंत्रीमंडल | **मंत्रिमंडल** | समास में 'मंत्री' का 'ई' ह्रस्व 'इ' हो जाता है |
| व्यवहारिक | **व्यावहारिक** | '-इक' प्रत्यय से वृद्धि |
| श्रीमति | **श्रीमती** | दीर्घ 'ई' |
| श्रोत | **स्रोत** | 'स' + 'र' (उद्गम, सोता); 'श्रोता' = सुनने वाला |
| सन्यासी | **संन्यासी** | सम् + न्यास |
| सन्मान | **सम्मान** | सम् + मान |
| सौहार्द्र | **सौहार्द** | अतिरिक्त 'र' नहीं |
| स्वास्थ | **स्वास्थ्य** | स्वस्थ + य |
| सौंदर्यता | **सौंदर्य** | दो प्रत्यय एक साथ |
| पैत्रिक | **पैतृक** | पितृ + इक |
| उतपन्न | **उत्पन्न** | उत् + पन्न |
| उपरी | **ऊपरी** | ऊपर → ऊपरी (दीर्घ 'ऊ') |
| प्रतिक्षा | **प्रतीक्षा** | प्रति + ईक्षा (दीर्घ संधि) |
| अंताक्षरी | **अंत्याक्षरी** | अंत्य + अक्षरी |
| प्रतिनिधी | **प्रतिनिधि** | ह्रस्व 'इ' |
| सप्ताहिक | **साप्ताहिक** | '-इक' प्रत्यय से वृद्धि (स → सा) |
| सामर्थ्यता | **सामर्थ्य** | दो प्रत्यय एक साथ |
| महत्वता | **महत्त्व / महत्व** | दो प्रत्यय एक साथ |
| इकठ्ठा | **इकट्ठा** | 'ट्' + 'ठ' |
| अंतर्ध्यान | **अंतर्धान** | अंतः + धान (लुप्त होना) |

> **याद रखें:** **केंद्रीय हिंदी निदेशालय** के मानक के अनुसार आधे नासिक्य वर्ण (ङ्, ञ्, ण्, न्, म्) के स्थान पर **अनुस्वार (ं)** लगाया जा सकता है: **हिंदी, संबंध, अंत** उतने ही शुद्ध हैं जितने हिन्दी, सम्बन्ध, अन्त। पूरे उत्तर में एक ही शैली अपनाएँ। परंतु जहाँ स्वर स्वयं नासिक्य हो, वहाँ **चंद्रबिंदु (ँ)** ही लगाएँ: **हँसना** (हँसी) ≠ **हंस** (पक्षी); **आँख, चाँद, गाँव, पाँच**।

## 2. लिंग

हिंदी में **दो लिंग** होते हैं — **पुल्लिंग** और **स्त्रीलिंग**। क्रिया, आकारांत विशेषण (जो '-आ' पर समाप्त हो) तथा का/के/की — सब संज्ञा के लिंग के अनुसार बदलते हैं।

### सहायक नियम

| वर्ग | लिंग | उदाहरण / अपवाद |
|---|---|---|
| दिन, महीने | पुल्लिंग | सोमवार, चैत, जनवरी |
| पर्वत, सागर | पुल्लिंग | हिमालय, सागर |
| ग्रह | पुल्लिंग | सूर्य, चंद्र, मंगल — परंतु **पृथ्वी** स्त्रीलिंग |
| धातुएँ, रत्न | पुल्लिंग | सोना, लोहा, हीरा — परंतु **चाँदी** स्त्रीलिंग |
| अनाज | पुल्लिंग | गेहूँ, चावल, चना — परंतु **दाल, मूँग, अरहर, मसूर** स्त्रीलिंग |
| भाषाएँ, लिपियाँ | स्त्रीलिंग | हिंदी, अंग्रेज़ी, संस्कृत, देवनागरी |
| नदियाँ | स्त्रीलिंग | गंगा, यमुना, कोसी — परंतु **सिंधु, ब्रह्मपुत्र, सोन** (नद) पुल्लिंग |
| '-त्व, -पन, -पा, -आव' अंत वाले शब्द | पुल्लिंग | मनुष्यत्व, बचपन, बुढ़ापा, बहाव |
| '-ता, -आई, -आवट, -आहट, -इमा' अंत वाले शब्द | स्त्रीलिंग | सुंदरता, पढ़ाई, सजावट, घबराहट, लालिमा, महिमा |
| '-ई' अंत वाले शब्द | प्रायः स्त्रीलिंग | रोटी, नदी — परंतु **पानी, घी, दही, मोती, जी** पुल्लिंग |

### प्रायः भ्रम पैदा करने वाली संज्ञाएँ

| पुल्लिंग | स्त्रीलिंग |
|---|---|
| दही, पानी, घी, मोती | पुस्तक, कलम, सड़क, चाय |
| आँसू, प्राण, हस्ताक्षर, दर्शन | आत्मा, देह, साँस, आयु |
| समाचार, विश्वास, सहयोग, सामान | सरकार, जनता, संसद, सेना |
| तापमान, अपमान, सम्मान, स्वभाव | मृत्यु, वायु, वस्तु, शपथ |
| व्यक्ति (स्त्रियों के लिए भी), ग्रंथ | परीक्षा, सलाह, चर्चा, दवा |
| होश, कंबल, विद्यालय | विजय, जय, आग, बर्फ़ |

> **सामान्य भूल:** "**सरकार ने नई योजना शुरू किया**" ✗ → "**सरकार ने नई योजना शुरू की**" ✓। यहाँ क्रिया **योजना** (स्त्रीलिंग) के अनुसार है, क्योंकि कर्ता के साथ 'ने' लगा है और कर्म के साथ 'को' नहीं है।

### स्त्रीलिंग बनाना (स्त्री-प्रत्यय)

| पुल्लिंग | स्त्रीलिंग | पुल्लिंग | स्त्रीलिंग |
|---|---|---|---|
| लड़का | लड़की | कवि | कवयित्री |
| बालक | बालिका | लेखक | लेखिका |
| माली | मालिन | धोबी | धोबिन |
| सेठ | सेठानी | देवर | देवरानी |
| शेर | शेरनी | मोर | मोरनी |
| विद्वान | विदुषी | श्रीमान | श्रीमती |
| भगवान | भगवती | नेता | नेत्री |
| युवक | युवती | साधु | साध्वी |
| अभिनेता | अभिनेत्री | सम्राट | सम्राज्ञी |

## 3. वचन

| नियम | एकवचन → बहुवचन |
|---|---|
| **'-आ'** अंत वाले पुल्लिंग → **'-ए'** | लड़का → लड़के; कमरा → कमरे |
| अन्य पुल्लिंग — कोई परिवर्तन नहीं | बालक → बालक; घर → घर; हाथी → हाथी |
| **'-इ/-ई'** अंत वाले स्त्रीलिंग → **'-इयाँ'** | नदी → नदियाँ; तिथि → तिथियाँ |
| **'-इया'** अंत वाले स्त्रीलिंग → **'-इयाँ'** | चिड़िया → चिड़ियाँ; गुड़िया → गुड़ियाँ |
| अन्य स्त्रीलिंग → **'-एँ'** | पुस्तक → पुस्तकें; माता → माताएँ; बहू → बहुएँ |
| परसर्ग लगने पर बहुवचन में **'-ओं'** | लड़कों ने, घरों में, नदियों का |

### सदा बहुवचन / सदा एकवचन

| सदा बहुवचन (नित्य बहुवचन) | सदा एकवचन (एकवचन में ही) |
|---|---|
| प्राण, दर्शन, हस्ताक्षर, आँसू, होश, लोग, समाचार (प्रायः) | जनता, सामान, पानी, दूध, सोना, वर्षा, आकाश, सत्य |

> **याद रखें:** **आदर** प्रकट करने के लिए बहुवचन का प्रयोग होता है: "**पिताजी आए हैं।**" "**गांधीजी सत्य के पुजारी थे।**" "पिताजी आया है" कभी न लिखें।

> **सामान्य भूल:** "**अनेकों**" अशुद्ध है — **अनेक** स्वयं बहुवचन है। "**अनेक पुस्तकें**" लिखें। इसी प्रकार "**प्रत्येक लड़कों को**" ✗ → "**प्रत्येक लड़के को**" ✓ ('प्रत्येक' के साथ एकवचन आता है)।

## 4. कारक और 'ने' का नियम

**परिभाषा:** संज्ञा या सर्वनाम के जिस रूप से उसका संबंध वाक्य के दूसरे शब्दों, विशेषकर क्रिया, से जाना जाए, उसे **कारक** कहते हैं। हिंदी में **8 कारक** हैं।

<div class="formula">

| कारक | चिह्न (परसर्ग) | उदाहरण |
|---|---|---|
| कर्ता | ने (या कोई चिह्न नहीं) | **राम ने** फल खाया। |
| कर्म | को | माँ ने **बच्चे को** सुलाया। |
| करण | से, के द्वारा | वह **कलम से** लिखता है। |
| संप्रदान | को, के लिए | **गरीबों के लिए** भोजन लाओ। |
| अपादान | से (अलग होने के अर्थ में) | पेड़ **से** पत्ते गिरे। |
| संबंध | का, के, की; रा, रे, री | यह **राम का** घर है। |
| अधिकरण | में, पर | किताब **मेज़ पर** है। |
| संबोधन | हे, अरे, ओ | **हे प्रभु!** रक्षा करो। |

</div>

### 'ने' का नियम (सबसे महत्त्वपूर्ण)

1. **सकर्मक क्रिया** के **सामान्य भूत, आसन्न भूत और पूर्ण भूत** (-आ/-ए/-ई वाले रूप) में कर्ता के साथ **'ने'** लगता है: "**राम ने पत्र लिखा।**"
2. **अकर्मक क्रियाओं** के साथ **'ने' नहीं** लगता: "राम हँसा", "वह सोया", "बच्चा रोया" — "राम ने हँसा" कभी नहीं।
3. **लाना, बोलना, भूलना** सकर्मक जैसी लगती हैं, फिर भी इनके साथ **'ने' नहीं** लगता: "**वह किताब लाया।**" ("उसने किताब लाई" नहीं); "**मैं भूल गया।**"
4. 'ने' लगने पर **क्रिया कर्म के अनुसार** होती है, कर्ता के अनुसार नहीं: "राम ने **रोटी** खा**ई**।" "सीता ने **पत्र** लिखा।"
5. यदि कर्म के साथ **'को'** लगा हो, तो क्रिया **पुल्लिंग एकवचन** में रहती है: "राम ने **सीता को** देख**ा**।"
6. **वर्तमान और भविष्यत् काल** में **'ने' नहीं** लगता: "राम पत्र लिखता है / लिखेगा।"

> **सामान्य भूल:** "**मैंने बोला**" बोलचाल में प्रचलित है, पर **मानक नहीं** है। "**मैंने कहा**" या "**मैं बोला**" लिखें।

## 6. वाक्य-विन्यास (वाक्य-रचना)

### वाक्य के अंग

हर वाक्य के दो अंग होते हैं — **उद्देश्य** (जिसके बारे में कुछ कहा जाए) और **विधेय** (उद्देश्य के बारे में जो कहा जाए)। "**मेहनती किसान | खेत में काम करता है।**" — उद्देश्य = मेहनती किसान; विधेय = खेत में काम करता है।

### रचना के आधार पर वाक्य-भेद

| भेद | पहचान | उदाहरण |
|---|---|---|
| **सरल वाक्य** | एक उद्देश्य, एक मुख्य क्रिया | वह परिश्रम करके सफल हुआ। |
| **संयुक्त वाक्य** | दो स्वतंत्र उपवाक्य, जो और, तथा, परंतु, किंतु, या, इसलिए से जुड़े हों | उसने परिश्रम किया **और** सफल हुआ। |
| **मिश्र वाक्य** | एक प्रधान उपवाक्य + एक या अधिक आश्रित उपवाक्य (जो, कि, क्योंकि, यदि, जब) | **क्योंकि** उसने परिश्रम किया, **इसलिए** वह सफल हुआ। / वह सफल हुआ **क्योंकि** उसने परिश्रम किया। |

#### निर्देशानुसार वाक्य-परिवर्तन के उदाहरण

| सरल | संयुक्त | मिश्र |
|---|---|---|
| वह खाना खाकर सो गया। | उसने खाना खाया **और** सो गया। | **जब** उसने खाना खा लिया, **तब** वह सो गया। |
| परिश्रमी छात्र सफल होते हैं। | छात्र परिश्रम करते हैं **और** सफल होते हैं। | **जो** छात्र परिश्रमी होते हैं, **वे** सफल होते हैं। |
| बीमार होने के कारण वह नहीं आया। | वह बीमार था, **इसलिए** नहीं आया। | वह नहीं आया **क्योंकि** वह बीमार था। |
| सूर्योदय होने पर अंधकार मिट गया। | सूर्योदय हुआ **और** अंधकार मिट गया। | **जब** सूर्योदय हुआ, **तब** अंधकार मिट गया। |
| मैंने एक ईमानदार व्यक्ति देखा। | मैंने एक व्यक्ति देखा **और** वह ईमानदार था। | मैंने एक व्यक्ति देखा **जो** ईमानदार था। |
| गरीब होने पर भी वह ईमानदार है। | वह गरीब है **परंतु** ईमानदार है। | **यद्यपि** वह गरीब है, **तथापि** ईमानदार है। |

> **स्मरण युक्ति:** **सरल** वाक्य में **-कर / -के कारण / -होने पर** आते हैं (एक ही क्रिया)। **संयुक्त** में **और / परंतु / इसलिए** (दो बराबर भाग)। **मिश्र** में **जो–वह / जब–तब / क्योंकि / यदि–तो / कि** (एक भाग दूसरे पर आश्रित)।

| **कर्तृवाच्य** | कर्ता पर | राम पत्र लिखता है। |
| **कर्मवाच्य** | कर्म पर; कर्ता के साथ **से / के द्वारा** | राम **द्वारा** पत्र लिखा जाता है। |
| **भाववाच्य** | क्रिया के भाव पर; अकर्मक क्रियाएँ; प्रायः 'से' के साथ निषेध में | मुझसे चला **नहीं जाता**। |

#### वाच्य-परिवर्तन के उदाहरण

| कर्तृवाच्य | कर्मवाच्य / भाववाच्य |
|---|---|
| मोहन पुस्तक पढ़ता है। | मोहन द्वारा पुस्तक पढ़ी जाती है। (कर्म) |
| सरकार ने नई नीति बनाई। | सरकार द्वारा नई नीति बनाई गई। (कर्म) |
| प्रधानमंत्री ने पुल का उद्घाटन किया। | प्रधानमंत्री द्वारा पुल का उद्घाटन किया गया। (कर्म) |
| मैं नहीं सो सकता। | मुझसे सोया नहीं जाता। (भाव) |
| बच्चा नहीं चल सकता। | बच्चे से चला नहीं जाता। (भाव) |
| वह हँस नहीं सकी। | उससे हँसा नहीं गया। (भाव) |

> **बिहार से जुड़ाव:** बिहार सरकार की सूचनाओं की राजभाषा हिंदी में **कर्मवाच्य** का प्रयोग बहुत होता है: "**आवेदन ऑनलाइन स्वीकार किए जाएँगे**", "**योजना का शुभारंभ किया गया**"। किसी अधिकारी को पत्र लिखते समय यही औपचारिक शैली उपयुक्त है।

## अभ्यास

### अभ्यास क — वाक्य शुद्ध कीजिए

1. मेरे को आपसे कुछ कहना है।
2. सीता ने गीत गाया और खाना बनाई।
3. उसका आँसू नहीं रुका।
4. हमारी सरकार गरीबों के लिए काम कर रहा है।
5. वह प्रातःकाल के समय नहाता है।
6. यह सबसे श्रेष्ठतम उपाय है।
7. उसने मुझे एक पुस्तक दिया।
8. यद्यपि वह थका था, परंतु काम करता रहा।
9. मोहन ने रोया।
10. प्रत्येक छात्रों को प्रमाण-पत्र मिलेगा।
11. दही बहुत मीठी है।
12. मैं आपका दर्शन करने आया हूँ।

### अभ्यास ख — वर्तनी शुद्ध कीजिए

1. आर्शीवाद  2. उज्वल  3. कवियत्री  4. स्वास्थ  5. श्रोत (उद्गम)  6. पश्चाताप  7. व्यवहारिक  8. मंत्रीमंडल

### अभ्यास ग — निर्देशानुसार वाक्य बदलिए

1. वह मेहनत करके पास हुआ। (संयुक्त वाक्य)
2. जो विद्यार्थी अनुशासित होते हैं, वे आगे बढ़ते हैं। (सरल वाक्य)
3. वर्षा हुई और फसल अच्छी हुई। (मिश्र वाक्य)
4. राधा गीत गाती है। (कर्मवाच्य)
5. मैं इस गर्मी में सो नहीं सकता। (भाववाच्य)
6. तुम परिश्रम करोगे तो सफल होगे। (अर्थ के आधार पर भेद बताइए)

### उत्तर

**क.**
1. मुझे आपसे कुछ कहना है।
2. सीता ने गीत गाया और खाना बनाया। (क्रिया 'खाना' — पुल्लिंग — के अनुसार)
3. उसके आँसू नहीं रुके।
4. हमारी सरकार गरीबों के लिए काम कर रही है।
5. वह प्रातःकाल नहाता है।
6. यह सबसे श्रेष्ठ उपाय है। / यह श्रेष्ठतम उपाय है।
7. उसने मुझे एक पुस्तक दी।
8. यद्यपि वह थका था, तथापि काम करता रहा।
9. मोहन रोया। ('रोना' अकर्मक क्रिया है)
10. प्रत्येक छात्र को प्रमाण-पत्र मिलेगा।
11. दही बहुत मीठा है।
12. मैं आपके दर्शन करने आया हूँ।

**ख.** 1. आशीर्वाद 2. उज्ज्वल 3. कवयित्री 4. स्वास्थ्य 5. स्रोत 6. पश्चात्ताप 7. व्यावहारिक 8. मंत्रिमंडल

**ग.**
1. उसने मेहनत की और पास हो गया।
2. अनुशासित विद्यार्थी आगे बढ़ते हैं।
3. जब वर्षा हुई, तब फसल अच्छी हुई। / क्योंकि वर्षा हुई, इसलिए फसल अच्छी हुई।
4. राधा द्वारा गीत गाया जाता है।
5. इस गर्मी में मुझसे सोया नहीं जाता।
6. संकेतवाचक (शर्तवाचक) वाक्य।
