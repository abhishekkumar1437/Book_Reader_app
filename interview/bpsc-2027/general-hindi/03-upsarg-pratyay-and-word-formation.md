व्याकरण खंड में प्रायः किसी शब्द से **उपसर्ग** या **प्रत्यय** अलग करने, दिए गए उपसर्ग से नए शब्द बनाने, अथवा किसी **तत्सम** शब्द का **तद्भव** रूप लिखने को कहा जाता है। ये प्रश्न छोटे और निश्चित उत्तर वाले होते हैं, इसलिए सूचियाँ याद हों तो हर प्रश्न पर आसानी से अंक मिलते हैं। इस अध्याय में ये सूचियाँ और उनके पीछे का तर्क दिया गया है।

> **सरल शब्दों में:** हर शब्द का एक **मूल** होता है (मूल शब्द या धातु)। मूल के **पहले** जुड़ने वाला अंश **उपसर्ग** है (प्र + हार = प्रहार)। मूल के **बाद** जुड़ने वाला अंश **प्रत्यय** है (लिख + आवट = लिखावट)। उपसर्ग प्रायः शब्द का **अर्थ बदलता** है; प्रत्यय प्रायः शब्द का **भेद बदलता** है (क्रिया से संज्ञा, संज्ञा से विशेषण)।

## शब्दों का वर्गीकरण

### रचना के आधार पर

| भेद | अर्थ | उदाहरण |
|---|---|---|
| **रूढ़** | जिनके सार्थक खंड न किए जा सकें | घर, पेड़, जल, हाथ, पानी, कल |
| **यौगिक** | जो सार्थक खंडों से बने हों और जिनका अर्थ खंडों के अर्थ का योग हो | विद्यालय (विद्या + आलय), पाठशाला, राजपुत्र, अनुचित |
| **योगरूढ़** | जो खंडों से बने हों, पर जिनका अर्थ किसी एक विशेष वस्तु के लिए रूढ़ हो गया हो | पंकज (कीचड़ में जन्मा — केवल कमल), लंबोदर (गणेश), जलज (कमल), दशानन (रावण), नीलकंठ (शिव) |

> **सामान्य भूल:** **पंकज** का शाब्दिक अर्थ है "कीचड़ में जन्म लेने वाला कोई भी", पर प्रयोग में इसका अर्थ केवल **कमल** है। इसीलिए यह **योगरूढ़** है, यौगिक नहीं। इसी प्रकार **जलज** का अर्थ कमल है, जल में रहने वाला हर जीव नहीं।

### उत्पत्ति के आधार पर

| भेद | अर्थ | उदाहरण |
|---|---|---|
| **तत्सम** | संस्कृत के वे शब्द जो हिंदी में ज्यों-के-त्यों प्रयुक्त होते हैं | अग्नि, दुग्ध, सूर्य, क्षेत्र, ग्राम |
| **तद्भव** | संस्कृत से आए वे शब्द जिनका रूप समय के साथ बदल गया | आग, दूध, सूरज, खेत, गाँव |
| **देशज** | भारत में ही जन्मे स्थानीय शब्द, जिनका मूल संस्कृत में नहीं मिलता | पगड़ी, लोटा, खिड़की, डिबिया, झंझट |
| **विदेशी** | विदेशी भाषाओं से आए शब्द | अरबी-फ़ारसी: किताब, अदालत, क़ानून; अंग्रेज़ी: स्कूल, बस, डॉक्टर; पुर्तगाली: अलमारी, चाबी, बाल्टी |
| **संकर** | दो भाषाओं के मेल से बने शब्द | रेलगाड़ी (रेल अंग्रेज़ी + गाड़ी हिंदी), टिकटघर, बमवर्षा |

> **स्मरण युक्ति:** तद्भव शब्द प्रायः **छोटे और कोमल** होते हैं: **क्ष → ख** (क्षेत्र → खेत), **श्व → स** (श्वसुर → ससुर), **ग्र → ग** (ग्राम → गाँव), **संयुक्त व्यंजन → सरल व्यंजन + अनुनासिक** (दंत → दाँत, सर्प → साँप)।

## भाग क — उपसर्ग

**परिभाषा:** वे शब्दांश जो किसी शब्द के **आरंभ** में जुड़कर उसके अर्थ में परिवर्तन या विशेषता ला देते हैं, **उपसर्ग** कहलाते हैं।

हिंदी में उपसर्गों के तीन वर्ग हैं: **संस्कृत के (22)**, **हिंदी के** और **उर्दू-फ़ारसी के**। इनके अतिरिक्त संस्कृत के कुछ **अव्यय भी उपसर्ग की तरह** प्रयुक्त होते हैं (अ, अन्, सह, स्व, चिर, पुनर् आदि) — ये भी पूछे जाते हैं।

### संस्कृत के 22 उपसर्ग

| उपसर्ग | अर्थ | उदाहरण |
|---|---|---|
| **अति** | अधिक, परे | अत्यंत, अतिरिक्त, अत्याचार, अतिशय, अतिक्रमण |
| **अधि** | ऊपर, श्रेष्ठ | अधिकार, अधिपति, अध्यक्ष, अधिनियम, अधिकरण |
| **अनु** | पीछे, समान | अनुकरण, अनुज, अनुसार, अनुराग, अनुवाद |
| **अप** | बुरा, विपरीत | अपमान, अपयश, अपकार, अपशब्द, अपराध |

| **अभि** | सामने, पास | अभिमान, अभियान, अभिनय, अभिषेक, अभ्यास |

| **उप** | निकट, छोटा | उपकार, उपदेश, उपवन, उपनाम, उपमंत्री |

परंपरागत 22 उपसर्गों की पूरी सूची यह है: प्र, परा, अप, सम्, अनु, अव, निस्, निर्, दुस्, दुर्, वि, आ, नि, अधि, अपि, अति, सु, उत्, अभि, प्रति, परि, उप। (निर्/निस् और दुर्/दुस् अलग-अलग गिने जाते हैं, इसीलिए ऊपर की तालिका में 22 उपसर्गों के लिए 20 पंक्तियाँ हैं।)

> **स्मरण युक्ति:** "**प्र-परा-अप-सम्, अनु-अव-निस्-निर्, दुस्-दुर्-वि-आ, नि-अधि-अपि-अति, सु-उत्-अभि-प्रति, परि-उप**" — इसे चार बार लय में बोलिए; यही परंपरागत क्रम है।

## भाग ख — प्रत्यय

### 1. कृत् प्रत्यय (धातु में जुड़ने वाले)

इनसे बने शब्द **कृदंत** कहलाते हैं।

| प्रत्यय | उदाहरण (धातु + प्रत्यय = शब्द) |
|---|---|
| -अक | लेख् + अक = **लेखक**; पठ् + अक = **पाठक**; गै + अक = **गायक**; नृत् + अक = **नर्तक** |
| -अन | भुज् + अन = **भोजन**; नी + अन = **नयन**; चल् + अन = **चलन** |
| -अनीय | पूज् + अनीय = **पूजनीय**; दृश् + अनीय = **दर्शनीय**; मन् + अनीय = **माननीय**; स्मृ + अनीय = **स्मरणीय** |
| -तव्य | कृ + तव्य = **कर्तव्य**; गम् + तव्य = **गंतव्य**; वच् + तव्य = **वक्तव्य** |
| -य | दा + य = **देय**; पा + य = **पेय**; कृ + य = **कार्य** |
| -ति | शक् + ति = **शक्ति**; गम् + ति = **गति**; प्री + ति = **प्रीति** |
| -आई | पढ़ + आई = **पढ़ाई**; लड़ + आई = **लड़ाई**; सिल + आई = **सिलाई** |
| -आवट | लिख + आवट = **लिखावट**; सज + आवट = **सजावट**; थक + आवट = **थकावट**; रुक + आवट = **रुकावट** |
| -आहट | घबरा + आहट = **घबराहट**; चिल्ला + आहट = **चिल्लाहट** |
| -आऊ | टिक + आऊ = **टिकाऊ**; बिक + आऊ = **बिकाऊ**; चल + आऊ = **चलाऊ** |
| -आक / -आका | तैर + आक = **तैराक**; लड़ + आका = **लड़ाका** |
| -अक्कड़ | भूल + अक्कड़ = **भुलक्कड़**; घूम + अक्कड़ = **घुमक्कड़**; पी + अक्कड़ = **पियक्कड़** |
| -इयल | अड़ + इयल = **अड़ियल**; मर + इयल = **मरियल**; सड़ + इयल = **सड़ियल** |
| -औना | खेल + औना = **खिलौना**; बिछ + औना = **बिछौना** |
| -नी | चट + नी = **चटनी**; ओढ़ + नी = **ओढ़नी**; मथ + नी = **मथनी** |
| -हार | पालन + हार = **पालनहार**; होन + हार = **होनहार** |
| -वाला | पढ़ने + वाला = **पढ़नेवाला**; गाने + वाला = **गानेवाला** |
| -कर | पढ़ + कर = **पढ़कर**; देख + कर = **देखकर** (पूर्वकालिक कृदंत) |

### 2. तद्धित प्रत्यय (संज्ञा, सर्वनाम, विशेषण में जुड़ने वाले)

| प्रत्यय | क्या बनाता है | उदाहरण |
|---|---|---|
| -ता | भाववाचक संज्ञा | सुंदर + ता = **सुंदरता**; मानव + ता = **मानवता**; मित्र + ता = **मित्रता**; एक + ता = **एकता** |
| -त्व | भाववाचक संज्ञा | मनुष्य + त्व = **मनुष्यत्व**; बंधु + त्व = **बंधुत्व**; नारी + त्व = **नारीत्व**; गुरु + त्व = **गुरुत्व** |
| -पन | भाववाचक संज्ञा | बच्चा + पन = **बचपन**; लड़का + पन = **लड़कपन**; पागल + पन = **पागलपन**; अपना + पन = **अपनापन** |
| -आई | भाववाचक संज्ञा | भला + आई = **भलाई**; चतुर + आई = **चतुराई**; अच्छा + आई = **अच्छाई** |
| -इमा | भाववाचक संज्ञा | लाल + इमा = **लालिमा**; महत् + इमा = **महिमा**; गुरु + इमा = **गरिमा** |
| -इक | विशेषण (पहले स्वर की वृद्धि होती है) | धर्म + इक = **धार्मिक**; समाज + इक = **सामाजिक**; इतिहास + इक = **ऐतिहासिक**; नीति + इक = **नैतिक**; दिन + इक = **दैनिक**; भूगोल + इक = **भौगोलिक** |
| -ईय | विशेषण | भारत + ईय = **भारतीय**; राष्ट्र + ईय = **राष्ट्रीय**; केंद्र + ईय = **केंद्रीय** |
| -ई / -ईण | विशेषण / संज्ञा | ग्राम + ईण = **ग्रामीण**; बिहार + ई = **बिहारी**; तेल + ई = **तेली**; रोग + ई = **रोगी** |
| -ईला | विशेषण | रंग + ईला = **रंगीला**; चमक + ईला = **चमकीला**; ज़हर + ईला = **ज़हरीला** |
| -वान / -मान | विशेषण ("वाला" के अर्थ में) | धन + वान = **धनवान**; गुण + वान = **गुणवान**; बुद्धि + मान = **बुद्धिमान**; शक्ति + मान = **शक्तिमान** |
| -आलु | विशेषण | दया + आलु = **दयालु**; कृपा + आलु = **कृपालु**; श्रद्धा + आलु = **श्रद्धालु** |
| -इत | विशेषण | पुष्प + इत = **पुष्पित**; आनंद + इत = **आनंदित**; पल्लव + इत = **पल्लवित** |
| -इन / -आनी | स्त्रीलिंग | माली + इन = **मालिन**; धोबी + इन = **धोबिन**; सेठ + आनी = **सेठानी**; देवर + आनी = **देवरानी** |
| -इया | लघुता (ऊनवाचक) | लोटा + इया = **लुटिया**; डिब्बा + इया = **डिबिया**; खाट + इया = **खटिया** |
| -एरा | संबंध | मामा + एरा = **ममेरा**; चाचा + एरा = **चचेरा**; फूफा + एरा = **फुफेरा** |
| -कार | कर्ता | चित्र + कार = **चित्रकार**; कला + कार = **कलाकार**; साहित्य + कार = **साहित्यकार** |
| -गर / -दार / -ची | कर्ता (फ़ारसी-तुर्की) | जादू + गर = **जादूगर**; दुकान + दार = **दुकानदार**; तबला + ची = **तबलची**; ख़ज़ाना + ची = **ख़ज़ांची** |

> **सामान्य भूल:** **"सौंदर्यता", "गौरवता", "माधुर्यता"** अशुद्ध हैं। सौंदर्य, गौरव, माधुर्य **पहले से ही** भाववाचक संज्ञाएँ हैं; इनमें फिर **-ता** जोड़ना दोहरा प्रत्यय है। शुद्ध रूप हैं **सौंदर्य, गौरव, माधुर्य**। (इसी प्रकार **"ऐक्यता"** अशुद्ध है → **ऐक्य** या **एकता**।)

> **सामान्य भूल:** **"इतिहासिक"** अशुद्ध → **ऐतिहासिक**; **"नीतिक"** अशुद्ध → **नैतिक**। **-इक** प्रत्यय लगने पर पहले स्वर की **वृद्धि** होती है (इ/ई → ऐ, उ/ऊ → औ, अ → आ)।

### उपसर्ग और प्रत्यय दोनों वाले शब्द

| शब्द | उपसर्ग | मूल | प्रत्यय |
|---|---|---|---|
| असफलता | अ | सफल | ता |
| निर्दयता | निर् | दया | ता |
| अनुभवी | अनु | भव | ई |
| प्रबंधक | प्र | बंध | अक |
| स्वतंत्रता | स्व | तंत्र | ता |
| अभिमानी | अभि | मान | ई |
| उपकारी | उप | कार | ई |
| अपमानित | अप | मान | इत |
| सुशिक्षित | सु | शिक्षा | इत |
| परिश्रमी | परि | श्रम | ई |
| अधार्मिक | अ | धर्म | इक |
| बेईमानी | बे | ईमान | ई |

> **परीक्षा की दृष्टि से:** जब पूछा जाए "उपसर्ग और मूल शब्द अलग कीजिए", तो उत्तर इस रूप में लिखें: **"प्रहार = प्र (उपसर्ग) + हार (मूल शब्द)"**। जब किसी उपसर्ग से तीन शब्द बनाने को कहा जाए, तो वे **प्रचलित शब्द** चुनें जिनके बारे में आप पूरी तरह आश्वस्त हों: प्र → प्रगति, प्रबल, प्रयोग।

> **बिहार से जुड़ाव:** बिहार सरकार की प्रशासनिक हिंदी के कई शब्द इन्हीं उपसर्गों और प्रत्ययों से बने हैं: **अधिसूचना** (अधि + सूचना), **प्रखंड** (प्र + खंड), **अनुमंडल** (अनु + मंडल), **ग्रामीण** (ग्राम + ईण), **सामाजिक** (समाज + इक)। ऐसे शब्दों का सही प्रयोग आपके निबंध को अच्छी प्रशासनिक हिंदी का रूप देता है।
