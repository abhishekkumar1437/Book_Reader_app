Three short question types sit together in this chapter because they test the same skill: seeing **how things are related**. An **analogy** asks "A is to B as C is to ?". **Classification** asks which item does not belong to a group. A **Venn diagram** question asks which picture of circles shows the relationship between groups, or asks you to count people in a region. BPSC uses all three, mostly at an easy level, and they are among the fastest marks in the paper.

> **In simple words:** Say the relationship between the first pair as a short sentence ("a doctor works in a hospital"). Then use the same sentence for the second pair. For odd-one-out, find what three items share; the fourth is the odd one. For Venn diagrams, ask "is one group inside the other, overlapping it, or separate from it?"

## Part A — Analogy

An **analogy** is a pair of things with a relationship, used to find a second pair with the **same** relationship. It is written A : B :: C : D, read "A is to B as C is to D".

### Common relationship types

<div class="formula">

| Type | Example |
|---|---|
| Worker and workplace | Doctor : Hospital :: Teacher : School |
| Tool and use | Pen : Write :: Knife : Cut |
| Capital and state / country | Patna : Bihar :: Bhopal : Madhya Pradesh |
| Part and whole | Petal : Flower :: Page : Book |
| Product and raw material | Paper : Wood :: Cloth : Cotton |
| Young one | Cow : Calf :: Dog : Puppy |
| Unit of measurement | Length : Metre :: Mass : Kilogram |
| Opposite | Hot : Cold :: Light : Dark |
| Number rule | 3 : 27 :: 4 : 64 (cube) |
| Letter rule | ACE : BDF :: GIK : HJL (+1 each) |

</div>

### Method

1. Make a **short sentence** for the first pair: "A ___ B".
2. Try the same sentence on each option.
3. If two options fit, make the sentence **more exact** (for example, "a doctor *treats patients in* a hospital").
4. For numbers: test square, cube, n² ± 1, n³ ± 1, × k, sum of digits.
5. For letters: compare positions letter by letter (shift, opposite letter).

### Solved examples — analogy

**Example 1.** Doctor : Hospital :: Teacher : ?

- A doctor works in a hospital. A teacher works in a **school**.

**Example 2.** Patna : Bihar :: Bhopal : ?

- Patna is the capital of Bihar. Bhopal is the capital of **Madhya Pradesh**.

**Example 3.** 3 : 27 :: 4 : ?

- 27 = 3³. So the answer is 4³ = **64**.

**Example 4.** 6 : 35 :: 8 : ?

- 35 = 6² − 1. So 8² − 1 = **63**.

**Example 5.** 7 : 50 :: 9 : ?

- 50 = 7² + 1. So 9² + 1 = **82**.

**Example 6.** ACE : BDF :: GIK : ?

- A → B, C → D, E → F: each letter +1.
- G → H, I → J, K → L → **HJL**.

**Example 7.** BAT : YZG :: CAP : ?

- B (2) → Y (25), A (1) → Z (26), T (20) → G (7): each pair adds to 27, so these are opposite letters.
- C (3) → X (24), A → Z, P (16) → K (11) → **XZK**.

**Example 8.** Pen : Write :: Knife : ?

- A pen is used to write. A knife is used to **cut**.

**Example 9.** Bihu : Assam :: Chhath : ?

- Bihu is a major festival of Assam. Chhath is a major festival of **Bihar** (also widely celebrated in Jharkhand and eastern Uttar Pradesh).

> **Bihar connection:** GK-flavoured analogies often use Indian states, capitals, festivals, dances, rivers and monuments. Bihar examples: Patna : Bihar; Chhath : Bihar; Madhubani painting : Mithila region; Bodh Gaya : Buddha's enlightenment; Nalanda : ancient university. These overlap with the [Bihar Special](/interview/bpsc-2027/bihar-special) book.

**Example 10.** 12 : 144 :: 15 : ?

- 144 = 12². So 15² = **225**.

## Part B — Classification (odd one out)

Three or four items share a property; one does not. Your job is to find the shared property.

### Common grouping properties

- **Numbers:** even/odd, prime/composite, perfect squares, perfect cubes, multiples of a number, sum of digits.
- **Letters:** same gap pattern, vowels, opposite pairs, positions.
- **Words:** category (fruits, rivers, metals), function, place, alloy vs metal, living vs non-living.

> **Common mistake:** Choosing the first difference you notice. Make sure the other **three** really share one clear property. If you can find two different "odd ones", look for the stronger, more exact rule.

### Solved examples — classification

**Example 11.** Find the odd one out: 3, 5, 7, 9, 11

- 3, 5, 7 and 11 are prime numbers. 9 = 3 × 3 is not.
- Odd one: **9**.

**Example 12.** Find the odd one out: Ganga, Kosi, Gandak, Chilika

- Ganga, Kosi and Gandak are rivers that flow through Bihar. Chilika is a lake (a coastal lagoon) in Odisha.
- Odd one: **Chilika**.

**Example 13.** Find the odd one out: 121, 144, 169, 196, 200

- 121 = 11², 144 = 12², 169 = 13², 196 = 14². 200 is not a perfect square.
- Odd one: **200**.

**Example 14.** Find the odd one out: ACE, BDF, GIK, MOP

- ACE, BDF, GIK: each skips one letter (+2, +2). MOP: M → O (+2), O → P (+1).
- Odd one: **MOP**.

**Example 15.** Find the odd one out: Silver, Gold, Copper, Brass

- Silver, gold and copper are metals (elements). Brass is an **alloy** (a mixture of copper and zinc).
- Odd one: **Brass**.

**Example 16.** Find the odd one out: 27, 64, 125, 144, 216

- 27 = 3³, 64 = 4³, 125 = 5³, 216 = 6³. 144 = 12² is not a cube.
- Odd one: **144**.

**Example 17.** Find the odd pair: (3, 9), (4, 16), (5, 25), (6, 30)

- In the first three pairs the second number is the square of the first. 6² = 36, not 30.
- Odd pair: **(6, 30)**.

### Solved examples — Venn diagrams

**Example 18.** Which picture best shows India, Bihar and Patna?

- Patna is a city in Bihar; Bihar is a state of India.
- **One circle inside another inside another** (picture 1).

**Example 19.** Which picture best shows Doctors, Men and Women?

- No person is both a man and a woman → Men and Women are **separate** circles.
- Some doctors are men and some are women → the Doctors circle **overlaps both** (picture 3).

**Example 20.** Which picture best shows Fruits, Mango and Vegetables?

- Every mango is a fruit → Mango inside Fruits.
- No fruit is a vegetable (in this classification) → Vegetables separate.
- **Picture 2.**

**Example 21.** In a group of 60 people, 35 like tea, 30 like coffee and 10 like both. How many like neither?

- People who like at least one = 35 + 30 − 10 = 55 (the 10 were counted twice).
- Neither = 60 − 55 = **5**.

**Example 22.** The diagram shows teachers (T), musicians (M) and dancers (D) in a town. Answer: (a) How many teachers are musicians but not dancers? (b) How many teachers are there in all? (c) How many dancers are not teachers? (d) How many people are only musicians? (e) How many people are in all three groups?

> **Prelims angle:** For "which diagram" questions, go group by group: is A inside B, overlapping B, or separate from B? Do the same for B–C and A–C. Three short answers fix the picture. For counting questions, read the question's "but not" carefully — it removes regions. ## Common traps

1. **Analogy direction:** "Doctor : Hospital" is worker : place. Do not answer "Patient : Hospital".
2. **Two possible number rules:** 2 : 8 could be ×4 or cube. Check with the options and, in harder questions, with a second pair.
3. **Odd one out by a weak property:** pick the rule that the other three clearly share.
4. **Venn: "some" vs "all".** Doctors are not all men → Doctors circle must not be inside Men.
5. **Counting "only" regions vs whole circles.** "Teachers" means the whole T circle; "only teachers" means the outer region.
6. **Double counting** in two-circle problems: subtract the overlap once.

## Quick revision

- Analogy: make a short sentence for the first pair; apply it to the second.
- Number analogies: square, cube, n² ± 1, n³ ± 1, × k.
- Letter analogies: shift or opposite letters (sum 27).
- Classification: find what three share; the fourth is odd.
- Brass is an alloy (copper + zinc); Chilika is a lake in Odisha.
- Venn patterns: inside, overlap, separate — decide pair by pair.
- Two sets: n(A or B) = n(A) + n(B) − n(both); neither = total − n(A or B).
- "But not" removes regions; "only" means outer regions.

## Key terms

| Term | Simple meaning |
|---|---|
| Analogy | Two pairs with the same relationship (A : B :: C : D) |
| Classification | Grouping items; finding the one that does not fit |
| Odd one out | The item that does not share the group's property |
| Set | A group of things (people, numbers, objects) |
| Venn diagram | Circles showing how sets are related |
| Overlap | The shared part of two circles — members of both sets |
| Disjoint | Two sets with nothing in common — separate circles |
| Subset | A set fully inside another set |
| Alloy | A mixture of metals (brass = copper + zinc) |

## Practice

### Problems

1. Cow : Calf :: Dog : ?
2. 5 : 124 :: 6 : ?
3. CFI : DGJ :: HKN : ?
4. Paper : Wood :: Cloth : ?
5. Odd one out: 2, 3, 5, 9, 13
6. Odd one out: Mars, Jupiter, Moon, Saturn
7. Odd one out: BCD, FGH, JKL, NPQ
8. Which Venn picture shows Animals, Dogs and Cats?
9. Which Venn picture shows Humans, Singers and Dancers?
10. In a class of 50, 28 play cricket, 20 play football and 8 play both. How many play neither?
11. Using the diagram of Example 22: how many people are dancers or musicians (or both)?

### Answers

1. The young one of a cow is a calf; of a dog, a **puppy**.
2. 124 = 5³ − 1 → 6³ − 1 = 216 − 1 = **215**.
3. Each letter +1: C → D, F → G, I → J. So H → I, K → L, N → O → **ILO**.
4. Paper is made from wood; cloth from **cotton**.
5. 2, 3, 5 and 13 are primes; 9 is not → **9**.
6. Mars, Jupiter and Saturn are planets; the Moon is a satellite of Earth → **Moon**.
7. BCD, FGH, JKL are three consecutive letters. NPQ is not (N → P skips O) → **NPQ**.
8. Dogs and Cats are both inside Animals and do not overlap each other → **two separate small circles inside one big circle**.
9. Every singer and every dancer is a human, and some singers are also dancers → **two overlapping circles (Singers, Dancers) inside one big circle (Humans)**.
10. At least one game = 28 + 20 − 8 = 40. Neither = 50 − 40 = **10**.
11. Union of D and M = everything except "only T": 8 + 10 + 5 + 4 + 3 + 2 = **32**. (Check: total 44 − only T 12 = 32 ✓.)
