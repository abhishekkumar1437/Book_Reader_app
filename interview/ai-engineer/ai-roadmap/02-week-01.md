## What each topic means

**Interpreter.** The program that reads your Python code and runs it line by line. When you type `python app.py`, the interpreter runs `app.py`.

**Virtual environment (venv).** A private folder of installed packages for one project. Project A can use one version of a library and project B another, without fighting. Create one with `python -m venv .venv`.

**pip.** The tool that installs Python packages. `pip install requests` downloads and installs the `requests` library into your active environment.

**Variable.** A name that points to a value. `score = 87` makes the name `score` point to the number 87.

**Type.** The kind of value. `87` is an `int` (whole number), `87.5` is a `float` (decimal number), `"Rahul"` is a `str` (text), `True` is a `bool`, `None` means "no value".

**Dynamic typing.** Python decides the type when the program runs, and a name can point to a different type later. `x = 5` then `x = "five"` is allowed.

**Operators.** Symbols that do work on values. `7 // 2` is floor division and gives `3`. `7 % 2` is the remainder and gives `1`. `2 ** 3` is power and gives `8`. `==` checks equal value; `is` checks same object.

**String slicing.** Taking part of a string by position. For `s = "cricket"`, `s[0:3]` is `"cri"` and `s[::-1]` is `"tekcirc"` (reversed).

**f-string.** A string with values put inside. `f"Total: ₹{total}"` with `total = 450` gives `"Total: ₹450"`.

**Control flow.** The order in which lines run. `if / elif / else` chooses a path. `for` repeats over items. `while` repeats while a condition is true. `break` leaves a loop early; `continue` skips to the next round.

**List.** An ordered, changeable collection: `marks = [78, 92, 65]`. You can add (`append`), remove, and change items.

**Tuple.** Like a list but cannot be changed after creation: `point = (3, 4)`. Use it for fixed groups of values.

**Mutable vs immutable.** **Mutable** objects can be changed in place (list, dict, set). **Immutable** ones cannot (int, float, str, tuple). `name.upper()` returns a new string; the old one is unchanged.

**Dictionary (dict).** Key–value pairs: `price = {"tea": 20, "samosa": 15}`. `price["tea"]` gives `20`. Lookups are very fast.

**Set.** An unordered collection with no duplicates: `{1, 2, 2, 3}` becomes `{1, 2, 3}`. Good for "have I seen this?" checks.

**Hashing.** The trick that makes dicts and sets fast. Python turns the key into a number (a **hash**) that says where to store it, so finding it takes about the same time whether there are 10 or 10 million items. This is called **O(1) average time**.

**Function.** A named block of reusable code. `def add(a, b): return a + b`. `a` and `b` are **parameters**; the values you pass in are **arguments**; `return` sends a result back.

**Default argument.** A parameter with a ready value: `def greet(name="friend")`. Never use a list or dict as a default (`def f(items=[])`), because the same list is shared by every call. Use `None` and create the list inside.

**`*args` and `**kwargs`.** Ways to accept any number of arguments. `*args` collects extra positional values into a tuple; `**kwargs` collects extra named values into a dict.

**Scope.** Where a name is visible. A variable created inside a function exists only inside that function (local scope).

**Module and import.** A module is a `.py` file of code. `import math` loads the `math` module so you can use `math.sqrt(16)`.

**Standard library.** The modules that come with Python: `math`, `random`, `json`, `csv`, `datetime`, `collections`, `pathlib`, and many more. No install needed.

**Exception.** An error that happens while the program runs, such as `ZeroDivisionError` or `KeyError`. `try / except` catches it so the program can respond instead of crashing.

**`with` statement (for files).** `with open("data.txt") as f:` opens a file and closes it automatically when the block ends, even if an error happens.

**Class and object.** A **class** is a blueprint; an **object** is one thing made from it. `class Student:` describes students; `s = Student("Priya", 91)` is one student. `__init__` sets up a new object, and `self` means "this object".

**Big-O notation (DSA).** A way to say how the running time grows with input size. **O(n)** means time grows in line with the number of items; **O(n²)** means it grows with the square, so 10 times more data takes about 100 times longer.

**Two pointers (DSA).** Two index variables that move through an array, often one from each end. For a sorted array, if the pair sum is too small, move the left pointer right; if too big, move the right pointer left. This turns many O(n²) problems into O(n).

## End-of-week self-check

Answer each out loud, without notes, then compare.

1. What is the difference between a list and a tuple, and when would you use a tuple?
2. Why is checking `x in my_set` faster than `x in my_list` for a large collection?
3. What does `print(7 // 2, 7 % 2, 2 ** 3)` print?
4. What is wrong with `def add_item(item, items=[])`? How do you fix it?
5. What does `with open("f.txt") as f:` do for you that `f = open("f.txt")` does not?
6. What is `self` in a class method?
7. In Two Sum II (sorted array), why is it safe to move the left pointer right when the sum is too small?
8. What are the time and space complexity of the two-pointer solution to Two Sum II?

**Answers**

1. A list can be changed (add, remove, update items); a tuple cannot. Use a tuple for a fixed group of values that belong together, like `(latitude, longitude)`, or as a dict key, because tuples of immutable items are hashable.
2. A set uses hashing, so it jumps directly to where the item would be: O(1) on average. A list must check items one by one: O(n).
3. `3 1 8`.
4. The default list is created once, when the function is defined, and is shared by all calls, so items from earlier calls stay in it. Fix: `def add_item(item, items=None):` and inside, `if items is None: items = []`.
5. It closes the file automatically when the block ends, even if an exception happens, so you never leak open files.
6. `self` is the object the method was called on. In `s.show()`, Python passes `s` as `self`.
7. The array is sorted, so the current right element is the largest still available. If even the left element plus the largest is too small, the left element cannot be part of any answer, so we can drop it.
8. O(n) time, because each pointer moves at most n steps, and O(1) extra space.
