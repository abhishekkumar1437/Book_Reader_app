Day 50 finishes your first portfolio project. From Day 51 you start Phase 4, deep learning. Neural networks power everything from image recognition to LLMs, and the ideas this week (forward pass, loss, backpropagation, optimizers) are the same ones used to train GPT-style models, just at a much bigger scale.

> **In simple words:** A neural network is many small units that each compute a weighted sum and pass it through a simple function. Training checks the error, works out how much each weight caused it (backpropagation), and nudges every weight to reduce it (the optimizer).

## What each topic means

**Portfolio README.** The front page of a project repo. It says the problem, the data, the approach, the results (with numbers), how to run it, and what you would improve. Recruiters often read only this.

**Neuron (perceptron).** The basic unit: multiply each input by a weight, add them up, add a bias, and pass the result through an activation function. The original **perceptron** used a simple step function (output 0 or 1).

**Weight and bias.** **Weights** say how important each input is. The **bias** shifts the result up or down, like the intercept b in y = wx + b. Both are learned.

**Layer.** A group of neurons that all take the same inputs. The **input layer** receives the features; **hidden layers** are in the middle; the **output layer** gives the prediction.

**Forward pass.** Computing the output from the input, layer by layer, using the current weights.

**Activation function.** A simple non-linear function applied after the weighted sum. Without it, stacking layers would still give only a straight-line (linear) model.

**Non-linearity.** Behaviour that is not a straight line. Real patterns (faces, language) are non-linear, so networks need non-linear activations to learn them.

**Sigmoid and tanh.** **Sigmoid** squashes to 0–1; **tanh** squashes to −1 to 1. Both flatten out for large inputs, which causes vanishing gradients in deep networks. Sigmoid is still used for binary outputs.

**ReLU.** ReLU(z) = max(0, z). Simple, fast, and the default for hidden layers in many networks. ReLU(−3) = 0, ReLU(2) = 2.

**Leaky ReLU.** Like ReLU, but negative inputs get a small slope (like 0.01z) instead of 0, so neurons never fully "die".

**GELU.** A smooth version of ReLU used in Transformers such as BERT and GPT.

**Softmax.** Turns the output scores for several classes into probabilities that add to 1. Scores [2, 1, 0] become about [0.665, 0.245, 0.090].

**Deep network.** A network with several hidden layers. Depth lets it build complex features from simple ones (edges → shapes → faces).

**Universal approximation.** A theorem saying a network with one large enough hidden layer can approximate almost any continuous function. In practice, deeper networks learn the same thing with far fewer neurons.

**Cross-entropy loss.** The standard loss for classification: −log(probability given to the correct class). If the model gives the correct class probability 0.665, loss = −ln(0.665) ≈ 0.41.

**Computational graph.** A diagram of every operation from inputs to loss. Frameworks like PyTorch build it automatically and use it to compute gradients.

**Backpropagation.** The algorithm that computes the gradient of the loss with respect to every weight, by applying the chain rule from the output backwards through the graph.

**Vanishing gradient.** When gradients get tiny as they flow back through many layers (for example, multiplying many sigmoid slopes, each at most 0.25), so early layers barely learn. ReLU, good initialisation, normalisation and skip connections help.

**Exploding gradient.** The opposite: gradients grow huge and training blows up (loss becomes NaN). Gradient clipping and a smaller learning rate help.

**Optimizer.** The rule that uses gradients to update weights.

**SGD.** Stochastic gradient descent: weight = weight − learning rate × gradient, using mini-batches.

**Momentum.** Keeps a running average of past gradients so updates keep moving in a consistent direction, like a ball rolling downhill. Reduces zig-zagging.

**RMSProp.** Divides each weight's step by a running average of its recent squared gradients, so each weight gets its own effective learning rate.

**Adam and AdamW.** **Adam** combines momentum and RMSProp; it is the most common default. **AdamW** applies weight decay correctly (separately from the gradient step) and is the standard for training Transformers.

**Learning-rate schedule.** Changing the learning rate during training, usually decreasing it (step decay, cosine decay) so the model settles into a good minimum.

**Warmup.** Starting with a very small learning rate and increasing it over the first steps. It prevents unstable early updates in large models.

**Batch size.** The number of examples per gradient step. Larger batches give smoother gradients and use the GPU better but need more memory; very large batches often need a larger learning rate or warmup.

**Binary tree (DSA).** Each node has at most two children, left and right. Most tree problems are solved with recursion: solve for the left and right subtrees, then combine.

**BST (Binary Search Tree) (DSA).** A binary tree where every left subtree has smaller values and every right subtree has larger values. An in-order traversal visits values in sorted order.

**DFS and BFS on trees (DSA).** **DFS** (depth-first search) goes deep down one branch first, usually with recursion. **BFS** (breadth-first search) visits level by level, using a queue.

## End-of-week self-check

1. What happens if you stack 10 linear layers with no activation functions?
2. Inputs [2, 3], weights [0.4, −0.2], bias 0.2. What is the output after ReLU?
3. Which activation would you use in the hidden layers, and which at the output for a 10-class problem?
4. What does backpropagation compute, and which rule from calculus does it use?
5. Why do sigmoid activations cause vanishing gradients in deep networks?
6. What does Adam do that plain SGD does not?
7. Your loss suddenly becomes NaN after 200 steps. Name two likely causes and fixes.
8. How do you check if a binary tree is a valid BST?

**Answers**

1. You get a single linear layer. A product of linear maps is still a linear map, so the network cannot learn non-linear patterns, however deep it is.
2. z = 0.4 × 2 + (−0.2) × 3 + 0.2 = 0.8 − 0.6 + 0.2 = 0.4. ReLU(0.4) = 0.4.
3. ReLU (or GELU) in hidden layers; softmax at the output, trained with cross-entropy loss.
4. It computes the gradient of the loss with respect to every weight and bias, using the chain rule from the output layer backwards.
5. The sigmoid's slope is at most 0.25 and near zero for large inputs. Backprop multiplies these slopes layer by layer, so the gradient shrinks towards zero for early layers.
6. Adam keeps a running average of gradients (momentum) and of squared gradients, and uses them to give each weight its own adaptive step size. It usually trains faster with less tuning.
7. Exploding gradients from a learning rate that is too high (lower it, add warmup, use gradient clipping), or a numerical problem such as log(0) or division by zero in the loss or data (check the inputs, use the framework's stable loss functions).
8. Do a DFS passing down an allowed range (low, high). Each node's value must be strictly inside the range; the left child gets (low, node value), the right child gets (node value, high). Or do an in-order traversal and check the values are strictly increasing.
