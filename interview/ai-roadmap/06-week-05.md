The first two days finish the math phase with the one idea all of ML training depends on: follow the gradient downhill to reduce the error. Then Phase 3 begins. You learn what machine learning is, how to prepare data (where most real-world effort goes), and your first model, linear regression.

> **In simple words:** A gradient tells you which way is "uphill" for the error. Step the other way and the model gets better. Machine learning is a program that learns rules from examples instead of you writing the rules, and good data matters more than a fancy model.

A gradient descent loop to type on Day 29:

```python
# Minimise y = (x - 3)^2. Its derivative is 2(x - 3).
x = 0.0
lr = 0.1                       # learning rate: step size
for step in range(1, 4):
    grad = 2 * (x - 3)
    x = x - lr * grad
    print(step, round(x, 4))
# Output:
# 1 0.6
# 2 1.08
# 3 1.464
```

Each step moves 20% of the remaining distance to 3, because the update is x − 0.1 · 2(x − 3) = 0.8x + 0.6.

## What each topic means

**Derivative (reminder).** The slope of a function at a point: how much the output changes for a tiny change in input. For y = x², the derivative is 2x.

**Partial derivative.** The derivative with respect to one input while keeping the others fixed. For f(x, y) = x² + 3y, ∂f/∂x = 2x and ∂f/∂y = 3.

**Gradient (∇).** The vector of all partial derivatives. It points in the direction where the function increases fastest. For f above, ∇f = [2x, 3].

**Chain rule.** How to differentiate a function inside a function: multiply the derivatives along the chain. If y = (2x + 1)², then dy/dx = 2(2x + 1) × 2. Backpropagation in neural networks is the chain rule applied layer by layer.

**Gradient descent.** Repeatedly move parameters a small step opposite to the gradient: new = old − learning rate × gradient. This lowers the error step by step.

**Learning rate (η).** The size of each step. Too small: training is very slow. Too large: you jump over the minimum and may never settle.

**Machine learning.** Instead of writing rules ("if the email has 'lottery', it is spam"), you give many labelled examples and an algorithm finds the rules. The result is a **model**: a function from inputs to predictions.

**Supervised learning.** Learning from examples that have the right answer (a **label**). Past loans marked "repaid" or "defaulted" train a model to predict new loans.

**Unsupervised learning.** Finding structure in data without labels, for example grouping customers by buying behaviour (**clustering**).

**Reinforcement learning.** An agent learns by trying actions and receiving rewards, like a game-playing program. It is also part of how LLMs are tuned (RLHF, Week 12).

**Regression vs classification.** **Regression** predicts a number (house price in ₹). **Classification** predicts a category (spam or not spam, which digit 0–9).

**Feature and label.** A **feature** is an input column (area, number of rooms, city). The **label** (or **target**) is what you want to predict (price).

**Training set and test set.** The model learns from the **training set**. The **test set** is held back and used once at the end to estimate performance on new data.

**Validation set.** A third part used while building the model, to choose settings and compare models, so the test set stays untouched.

**ML workflow.** Define the problem → collect data → EDA → prepare features → split → train → evaluate → tune → deploy → monitor.

**Missing values and imputation.** Missing values are empty cells. **Imputation** fills them, for example with the median of the column, or with a new category "Unknown".

**Outlier.** A value far from the others, like a ₹50 crore flat in a list of ₹50 lakh flats. It may be an error or a rare real case; check before removing.

**One-hot encoding.** Turning a category into 0/1 columns. City ∈ {Pune, Delhi, Chennai} becomes three columns; Delhi is [0, 1, 0]. Use it when categories have no order.

**Label encoding.** Replacing categories with numbers: Low = 0, Medium = 1, High = 2. Good when there is a natural order; bad for unordered categories with linear models, because it invents an order.

**Target encoding.** Replacing a category with the average label for that category (for example the average price per city). Powerful, but it can leak the label if not done inside cross-validation.

**Standard scaling.** Rescale a column to mean 0 and standard deviation 1: z = (x − mean) / std. For marks [50, 60, 70], mean is 60 and std ≈ 8.16, so 70 becomes ≈ 1.22.

**Min-max scaling.** Rescale to the range 0 to 1: (x − min) / (max − min). For [50, 60, 70], 60 becomes 0.5.

**Data leakage.** When information that would not be available at prediction time sneaks into training, so test scores look great but the real model fails. Examples: scaling using the whole dataset before splitting, or using "refund issued" to predict "order cancelled".

**Imbalanced data.** When one class is rare, like 1% fraud. A model that always says "not fraud" gets 99% accuracy and is useless.

**SMOTE.** A method that creates new synthetic examples of the rare class by mixing neighbouring rare examples. Apply it only to the training data.

**Class weights.** Telling the model that mistakes on the rare class cost more. In scikit-learn: `class_weight="balanced"`.

**Feature engineering.** Creating better inputs from raw data: "day of week" from a date, "price per square foot", "number of orders in the last 30 days". Often improves a model more than changing the algorithm.

**Linear regression.** A model that predicts a number as a weighted sum of features plus a constant: ŷ = w₁x₁ + w₂x₂ + b. Training finds the weights that make predictions closest to the real values.

**MSE (Mean Squared Error).** The average of squared errors. Actual [3, 5], predicted [2, 5]: errors 1 and 0, squares 1 and 0, MSE = 0.5. Squaring punishes big mistakes more.

**R² (coefficient of determination).** How much of the variation in the target the model explains. 1 is perfect; 0 means no better than always predicting the mean.

**Closed-form solution.** A formula that gives the best linear regression weights directly (the normal equation), without gradient descent. It is slow for very many features, which is one reason gradient descent is used.

**Linked list (DSA).** A chain of nodes where each node stores a value and a pointer to the next node. Inserting at a known spot is O(1), but reaching the i-th item is O(n).

**Dummy node and fast/slow pointers (DSA).** A **dummy node** is a fake head that removes special cases when the real head changes. **Fast/slow pointers** move at different speeds to find the middle of a list or detect a cycle.

## End-of-week self-check

1. Do one gradient descent step on y = (x − 3)² from x = 5 with learning rate 0.1.
2. What is the chain rule, and where is it used in deep learning?
3. Predicting tomorrow's temperature and predicting "will it rain tomorrow": which is regression, which is classification?
4. Why must you fit the scaler on the training data only?
5. When would you use one-hot encoding instead of label encoding?
6. A fraud dataset has 1% fraud. Why is accuracy a bad metric here, and what can you do during training?
7. Actual prices [10, 20, 30], predicted [12, 18, 30]. What is the MSE?
8. How do you find the middle of a linked list in one pass?

**Answers**

1. Gradient = 2(5 − 3) = 4. New x = 5 − 0.1 × 4 = 4.6, which is closer to 3.
2. The derivative of a composed function is the product of the derivatives of its parts. Backpropagation uses it to pass the error gradient from the output layer back through every layer to every weight.
3. Temperature (a number) is regression. Rain yes/no (a category) is classification.
4. If you fit it on all data, the mean and standard deviation include test data, so information from the test set leaks into training and your test score becomes too optimistic.
5. When the categories have no natural order, like city or colour. Label encoding would make a linear model think Chennai (2) is "twice" Delhi (1).
6. A model that always says "not fraud" gets 99% accuracy but catches nothing. Use class weights or SMOTE on the training set, and evaluate with recall, precision or PR-AUC.
7. Errors are −2, 2, 0. Squares 4, 4, 0. MSE = 8 / 3 ≈ 2.67.
8. Use slow and fast pointers. Slow moves 1 step, fast moves 2. When fast reaches the end, slow is at the middle.
