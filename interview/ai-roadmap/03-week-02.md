NumPy drills for Day 13 and Day 14 (type them, do not copy):

```python
import numpy as np

marks = np.array([[78, 92, 65], [88, 45, 70], [55, 60, 95]])  # 3 students x 3 subjects
print(marks.shape)          # (3, 3)
print(marks[1])             # second student's marks: [88 45 70]
print(marks[:, 2])          # third subject for everyone: [65 70 95]
print(marks[marks > 80])    # all marks above 80: [92 88 95]
print(marks * 1.1)          # 10% grace on every mark, no loop needed
print(marks.reshape(1, 9))  # same 9 numbers, new shape
```

## What each topic means

**Inheritance.** Making a new class that reuses an existing class. `class Dog(Animal):` means a Dog gets everything Animal has, and can add or change things. In PyTorch every model is `class MyModel(nn.Module):`.

**`super()`.** Calls the parent class's version of a method. `super().__init__()` runs the parent's set-up code before yours.

**Dunder methods.** Special methods with double underscores, like `__init__`, `__repr__`, `__len__`, `__eq__`, `__add__`. Python calls them for you: `len(x)` calls `x.__len__()`, `a + b` calls `a.__add__(b)`.

**Iterable and iterator.** An **iterable** is anything you can loop over (list, string, file). An **iterator** is the object that gives the next item each time you call `next()`, and stops with `StopIteration` when items run out.

**Generator.** A function that uses `yield` instead of `return`. It produces values one at a time, only when asked. Reading a 10 GB log file line by line with a generator uses almost no memory.

**Lazy evaluation.** Computing a value only when it is needed. Generators, `range`, `map` and `zip` are lazy.

**Decorator.** A function that wraps another function to add behaviour. `@timer` above `def train():` means "run `train`, but also time it". FastAPI uses decorators like `@app.get("/")` to connect URLs to functions.

**Closure.** An inner function that remembers variables from the outer function, even after the outer function has finished. Decorators are built from closures.

**List comprehension.** A short way to build a list. `[x * x for x in range(5) if x % 2 == 0]` gives `[0, 4, 16]`.

**`lambda`.** A small unnamed function in one line. `sorted(students, key=lambda s: s["marks"])` sorts students by marks.

**`map`, `filter`, `zip`, `enumerate`.** `map` applies a function to every item; `filter` keeps items that pass a test; `zip` pairs items from two lists; `enumerate` gives `(index, item)` pairs.

**Reference.** In Python a variable holds a reference (an arrow) to an object, not the object itself. `b = a` makes both names point to the same list, so changing `b` also changes `a`.

**Shallow vs deep copy.** A **shallow copy** (`a.copy()`) makes a new outer list, but inner lists are still shared. A **deep copy** (`copy.deepcopy(a)`) copies everything inside too.

**Context manager.** An object used with `with` that sets something up and always cleans it up afterwards: open/close a file, lock/unlock, start/stop a timer.

**Thread vs process.** A **thread** is a separate line of work inside one program, sharing memory. A **process** is a separate program with its own memory. Threads are good for waiting on network or disk; processes are good for heavy CPU work.

**GIL (Global Interpreter Lock).** A lock in standard CPython that lets only one thread run Python code at a time. So threads do not speed up CPU-heavy Python code, but they still help when threads spend time waiting (for example for API responses). Python 3.13+ also offers an experimental "free-threaded" build without the GIL; interviews still expect you to know the classic rule.

**async / await.** A way to handle many waiting tasks in one thread. While one task waits for an API, the **event loop** runs another. LLM apps use this to call many APIs at once. `await asyncio.gather(call1(), call2())` runs both concurrently.

**Type hints.** Labels that say what type a value should be: `def total(prices: list[float]) -> float:`. Python does not enforce them at run time, but tools like `mypy` and editors use them to catch bugs. Pydantic and FastAPI use them for validation.

**pytest.** The most common Python testing tool. Write functions named `test_...` that use `assert`, then run `pytest`.

**Linting and formatting.** Tools that check style and common bugs (`ruff`) and auto-format code (`ruff format` or `black`).

**NumPy.** A library for fast arrays of numbers. Its operations run in compiled C code, so `a * 2` on a million numbers is far faster than a Python loop.

**ndarray.** NumPy's array type. All items have the same type, which is what makes it fast.

**dtype.** The type of the items in an array, for example `int64`, `float32` or `bool`. Deep learning often uses `float32` to save memory.

**shape.** The size of each dimension. A 3×4 array has `shape == (3, 4)`: 3 rows, 4 columns.

**Vectorization.** Doing a calculation on a whole array at once instead of looping. `prices * 1.18` adds 18% GST to every price in one line.

**Boolean mask.** An array of True/False used to pick items. `marks[marks > 80]` keeps only marks above 80.

**reshape.** Changing the shape without changing the data. 12 numbers can be shape `(3, 4)`, `(4, 3)`, `(2, 6)` or `(12,)`.

**Sliding window (DSA).** A pattern for problems about contiguous parts of an array or string. Keep a "window" between two pointers; grow it from the right, and shrink it from the left when it breaks a rule. Each item enters and leaves once, so the time is O(n).

## End-of-week self-check

1. What is the difference between a generator and a normal function that returns a list?
2. What does a decorator do, in one sentence? Give one place where AI code uses decorators.
3. `a = [[1, 2], [3, 4]]; b = a.copy(); b[0].append(9)`. What is `a` now, and why?
4. Why do threads not speed up a CPU-heavy pure-Python loop?
5. When is `asyncio` a good choice?
6. What is vectorization in NumPy, and why is it faster than a loop?
7. An array has shape `(3, 4)`. Can you reshape it to `(2, 6)`? To `(5, 2)`?
8. In the sliding window template, when do you shrink the window?

**Answers**

1. A generator produces items one at a time when asked, and keeps only its current state in memory. A function returning a list builds the full list in memory first. Use generators for large or endless data.
2. A decorator wraps a function to add behaviour before or after it runs, without changing its code. FastAPI's `@app.get("/path")` and PyTorch's `@torch.no_grad()` are examples.
3. `a` is `[[1, 2, 9], [3, 4]]`. `copy()` is shallow: the outer list is new, but the inner lists are shared, so appending to `b[0]` changes the same inner list that `a[0]` points to.
4. Because of the GIL, only one thread runs Python bytecode at a time, so CPU work is not done in parallel. Use multiple processes (or NumPy, which does the heavy work in C) instead.
5. When the program spends most of its time waiting for input/output, like many API calls or database queries at once. One thread can handle thousands of waiting tasks.
6. Vectorization means one operation on the whole array, such as `a * 2`. The loop runs in fast compiled C code instead of slow Python steps, and it can use CPU vector instructions.
7. Yes to `(2, 6)`, because 2 × 6 = 12 = 3 × 4. No to `(5, 2)`, because 5 × 2 = 10, not 12.
8. When the window breaks the problem's rule (for example, it has a repeated character, or its sum is already at least the target). Shrink from the left until the rule holds again.
