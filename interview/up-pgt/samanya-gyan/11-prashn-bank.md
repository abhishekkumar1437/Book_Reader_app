## Attempt strategy in the exam (+3 / −1)

| Situation | Expected value | Decision |
|---|---|---|
| Sure of the answer | +3 | Attempt immediately |
| Two options eliminated (1/2 chance) | (3 − 1)/2 = **+1** | **Attempt** |
| One option eliminated (1/3 chance) | (3 − 2)/3 = **+0.33** | If time allows, carefully |
| No idea (1/4 chance) | (3 − 3)/4 = **0** | **Leave it** |

- GK section **first**, at most **18–20 minutes**.
- In "not correctly matched" questions check each pair separately — as soon as one pair is surely wrong, keep the options that include it and eliminate the rest.
- In current affairs answer only on facts you have **actually read**; a name that "sounds familiar" is a trap.
- Fill the OMR every 10 questions.
