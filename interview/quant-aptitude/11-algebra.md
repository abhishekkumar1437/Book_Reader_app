## Where it appears

SSC: two or three questions, mostly identity manipulation (given x + 1/x, find x³ + 1/x³) and quadratic relations. CSAT and BPSC: word problems that reduce to one or two linear equations (ages, numbers, coins). This chapter is short on theory and long on the patterns.

## Word problems to linear equations

**Example.** A father is three times as old as his son; in 12 years he will be twice as old. Ages?
f = 3s; f + 12 = 2(s + 12) → 3s + 12 = 2s + 24 → s = 12, f = 36.

**Example.** Two numbers differ by 5 and their sum is 33. The numbers?
(33 + 5)/2 = 19 and 14. **Hint:** sum and difference given → larger = (sum + diff)/2.

**Example.** A purse has ₹5 and ₹2 coins, 40 coins worth ₹140. How many ₹5 coins?
5x + 2(40 − x) = 140 → 3x = 60 → x = 20.

**Example.** The sum of the digits of a two-digit number is 11; reversing the digits gives a number 27 more. The number?
a + b = 11, b − a = 3 → b = 7, a = 4 → 47.

**Example.** Five years ago, A was 3 times as old as B; 10 years hence, A will be twice as old. Present ages?
(A − 5) = 3(B − 5); (A + 10) = 2(B + 10). From the first, A = 3B − 10; then 3B = 2B + 20 → B = 20, A = 50.

## The x + 1/x family

**Example.** x + 1/x = 5. Find x² + 1/x², x³ + 1/x³, x − 1/x.
25 − 2 = 23; 125 − 15 = 110; (x − 1/x)² = 25 − 4 = 21 → √21.

**Example.** x² − 5x + 1 = 0. Find x + 1/x. Divide by x: x − 5 + 1/x = 0 → x + 1/x = 5.

**Example.** If x + 1/x = 2, find x^10 + 1/x^10. x = 1, so 2.

**Example.** If x² + 1/x² = 7 (x > 0), find x³ + 1/x³. (x + 1/x)² = 9 → 3; then 27 − 9 = 18.

**Example.** If a + b + c = 0, find (a³ + b³ + c³)/abc. = 3.

**Example.** If a + b = 7 and ab = 12, find a³ + b³. = 343 − 3 × 12 × 7 = 343 − 252 = 91. (a, b = 3, 4: 27 + 64 = 91.)

**Example.** If x + y = 10 and x − y = 4, find x² − y² = 10 × 4 = 40.

## Quadratics

**Example.** Solve x² − 7x + 12 = 0. Factor: (x − 3)(x − 4) → 3, 4.

**Example.** Roots of 2x² − 5x + 3 = 0: sum 5/2, product 3/2. Roots 1 and 3/2.

**Example.** For what k does x² + kx + 16 = 0 have equal roots? k² = 64 → k = ±8.

**Example.** If α, β are roots of x² − 6x + 4 = 0, find α² + β². (α + β)² − 2αβ = 36 − 8 = 28.

**Example.** Form the quadratic with roots 2 and −5: x² − (sum)x + product = x² + 3x − 10 = 0.

## Progressions

**Example.** 10th term of 3, 7, 11, ...: 3 + 9 × 4 = 39. Sum of the first 20 terms: 20/2 × (6 + 19 × 4) = 10 × 82 = 820.

**Example.** Which term of 5, 8, 11, ... is 302? 5 + (n − 1)3 = 302 → n = 100.

**Example.** Sum of 2 + 4 + 8 + ... to 10 terms = 2(2^10 − 1) = 2046.

**Example.** 1 + 1/3 + 1/9 + ... = 1/(1 − 1/3) = 3/2.

**Example.** How many terms of 2, 5, 8, ... sum to 155? n/2 [4 + 3(n − 1)] = 155 → n(3n + 1) = 310 → 3n² + n − 310 = 0 → n = 10.

## Inequalities and options

For CSAT-style "which of the following must be true" with variables, test small numbers including 0, 1, negatives, and fractions. For "find the value" questions with awkward algebra, substitute the options.

## Traps

- (a − b)² ≠ a² − b². Sign errors on the cross term are the most common algebra slip.
- x + 1/x = 2 forces x = 1; x + 1/x = −2 forces x = −1; other values in (−2, 2) have no real x.
- "Twice as old as" is × 2; "twice as old as he was" refers to a past age.
- Equal roots need D = 0, not D > 0.
- Sum of an AP uses the number of terms, not the last term.

## Practice set

1. x + 1/x = 4. Find x³ + 1/x³ and x⁴ + 1/x⁴.
2. x² − 3x + 1 = 0. Find x² + 1/x².
3. a + b = 9, ab = 20. Find a² + b² and a³ + b³.
4. If a + b + c = 6 and ab + bc + ca = 11, find a² + b² + c².
5. Solve x² + x − 12 = 0.
6. If one root of x² − 5x + k = 0 is 2, find k and the other root.
7. Mother is 25 years older than her son; 5 years ago she was 6 times as old. Son's age now?
8. A two-digit number is 4 times the sum of its digits, and the digits differ by 3 (units greater). Number?
9. 15th term and sum of 15 terms of 7, 10, 13, ...
10. Sum of the infinite series 5 + 5/4 + 5/16 + ...
11. Sum of all odd numbers from 1 to 99.
12. If x = 7 + 4√3, find √x + 1/√x.

**Answers**

1. 64 − 12 = 52; (16 − 2)² − 2 = 194.
2. x + 1/x = 3 → 9 − 2 = 7.
3. 81 − 40 = 41; 729 − 3 × 20 × 9 = 729 − 540 = 189 (a, b = 4, 5: 64 + 125).
4. 36 − 22 = 14.
5. (x + 4)(x − 3) → −4, 3.
6. 4 − 10 + k = 0 → k = 6; other root = 6/2 = 3.
7. m = s + 25; s + 20 = 6(s − 5) → 5s = 50 → s = 10.
8. 10a + b = 4(a + b) → 6a = 3b → b = 2a; b − a = 3 → a = 3, b = 6 → 36.
9. 7 + 14 × 3 = 49; sum = 15 × (7 + 49)/2 = 420.
10. 5/(1 − 1/4) = 20/3.
11. 50 odd numbers, average 50 → 2,500 (= 50²).
12. x = (2 + √3)², so √x = 2 + √3 and 1/√x = 2 − √3 → 4.
